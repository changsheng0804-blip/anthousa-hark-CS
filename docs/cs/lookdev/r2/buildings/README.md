## 做了什么
- **房子不再是白模**：墙按整层数贴程序化立面（灰泥 + 层间砖线 / 砖石夹层 opus mixtum），窗洞、门、过梁、窗台、百叶；铺面（shops / market / dock）底层是整开间的大洞 + 柜台 + 货。屋顶改成美术圣经的 ≈23° 缓坡、出檐、檐底深色板、屋脊和斜脊压白灰。墙色/瓦色按户由 `ctx.hsh` 定（sRGB 调色板转线性再当顶点色）。
- **柱廊**：面向 m 街（或 s 街上的铺面 / 底账 `po=1`）的户，前墙在占地以内退进一个廊深（≤ 4 像素），原墙线上立柱（InstancedMesh）、架额枋、搭单坡瓦顶、廊下深色天花。不侵占街面。临街边先读 streets 写的 `ctx.reg.frontage`（v1：`sides[]` 里 `house` 指到的户，取离那个街边点最近的墙），读不到（或那户不在 sides 里）就按最近的 m/s 街段（平行、距离 ≤ 半街宽 + 14/6）自己算。第 60 年合并后：1929 户的临街边来自 streets，1062 户有柱廊，2557 根柱。
- **粮仓**：底账矩形内排一排并肩的山墙长仓（山墙朝短边，即码头一侧），砖石夹层墙、扶壁、长墙上的拱门和高窗、山墙上的大拱门（木板门）+ 拱窗 + 圆窗 + 壁柱、大门上的单坡瓦檐和木撑。仓高 15.5–18 像素（底账没给地标高度，按两层国家粮仓取）。
- **水道桥**：`aq_hadrian` 沿折线建出拱廊。桥面按地势的大尺度平均高 + 36 像素（≈ 30 m）走，桥墩落地，谷里自然出现多层；拱洞是贴图透明（alphaTest + 自定义深度材质，影子也透拱）。
- 一种材质一个合并网格：9 个网格 + 1 个柱子实例网格 + 地标组 + 栈桥网格。栈桥、石堤、宁芙殿水池、穹顶、纪念柱几何照旧。

## 机位 1 为什么没到 0.18
- 这条带的上 30%（0.25–0.355）是天空，城只占 0.355–0.56 一窄条（基线报告已记：机位 1 城太远太扁）。城那一条里边缘已 ≈ 0.25，天际线上的水道桥那一行 ≈ 0.52。
- 远处房子 5–15 像素宽，立面细节在 mip 里被平均掉，再加贴图也不涨（试过：调色板、铺面大洞、屋脊白灰，都在 ±0.003 内）。剩下的差距主要靠光：低太阳的长投影和受光/背光面的反差（sky 的事）。沙箱里试过把太阳压低变暗，这条带反而降到 0.145——边缘数字跟着 sky 走，合并后要重测。
- 不愿意为凑数字去拔高房子（底账高度）或把水道桥抬到不合史实的高度。
