## 史料（底账没写的）

- 狄奥多西 393 年仿罗马图拉真广场重建君士坦丁的陶里广场，中间立纪功柱；西侧一座普罗科奈索斯大理石凯旋门，三个门洞、中门更宽更高，**四个墩子每个是 4 根束柱，柱子雕成赫拉克勒斯的棍棒、有一只拳头握着**；顶上狄奥多西居中、两边阿卡狄乌斯和霍诺留的像。——https://en.wikipedia.org/wiki/Forum_of_Theodosius （引 turkisharchaeonews.net/object/theodosius-forum）
- 中门原宽约 7 m，每个墩座上 4 根装饰柱，纹样同地下水宫（Basilica Cistern）的柱子（「孔雀眼 / 泪滴」）；凯旋门跨在 Mese 上。——https://www.thebyzantinelegacy.com/theodosius-arch
- Naumann 复原图的描述：「三个筒拱、柱子装饰得像赫拉克勒斯的棍棒、科林斯柱头，其中四根柱头下有手」。——https://historica.unibo.it/entities/publication/3c56bf6c-6e63-477f-823a-ba2b0d6fa5d6 （Naumann 1976, *Istanbuler Mitteilungen* 26, 117–141）
- Byzantium 1200：凯旋门是广场的入口之一，「代替墩柱的是装饰成树干的束柱」，两侧门可能是后加的。——https://www.byzantium1200.com/tauri.html
- Columbia「Istanbul Documentation Project」：东、西两个主入口各一座凯旋门，另有大会堂（Basilica Theodosiana）、纪功柱、一批荣誉像。——https://mcid.mcah.columbia.edu/istanbul-documentation-project/forum-theodosius
- 广场大小：老说法 450 × 300 m 早被推翻；Byzantium 1200 按地基残墙复原成约 55 × 55 m、北面一个半圆龛。——https://web.archive.org/web/20080509085225/http:/www.byzantium1200.com/forum-t.html 。**底账给的是 119 × 96 m，照底账**（底账优先）。

## 假设（底账和史料都没定的，可推翻）

1. **柱廊两层**（dna peristyle + monumental；图拉真广场是单层柱廊 + 后面的建筑，这里合成一圈两层柱廊）：下层科林斯柱（钟形 + 顶板的远档柱头），上层矮柱 + 柱间栏板；进深 11 px ≈ 9.2 m、柱距 3.2 m、柱心离院边 1.25 px。
   高（米，实际比例 → ×PORTICO_SCALE 1.2）：台基 + 两级台阶 → 下层柱顶 6.0 → 下层檐 6.9 → 栏板 8.0 → 上层柱顶 11.3 → 上层檐 12.0 → 单坡瓦顶到 13.8 → 外墙压顶 14.1（×1.2 = 16.9 m ≈ 20.1 px；周边民居屋顶中位数 ≈ 8 px）。
2. **外墙**：砖带石（4–5 皮砖一道石），下层每两开间一个拱形铺面门洞、其余是高窗，上层每开间一个拱窗，外皮一道腰线和墙脚石；**柱廊里的内墙刷赭色灰泥**（好让白柱子跳出来；史料没说）；瓦顶单坡朝院子。
3. **凯旋门**：总宽 28.2 m、深 4 m；中门 7 m（史料）、侧门 4.2 m（第 2 轮按参考的宽高比放宽，史料没给）；墩座 2.2 m → 棍棒束柱 9.6 m（柱径 0.84 m，2×2 一束，柱心距 1.5 m）→ 墩顶檐块到 13.0 m 起拱 → 拱身 + 檐口到 19.0 → 女儿墙（题额 + 两个月桂花环 + 对着墩子的壁柱）到 22.0–22.5，中段加高到 23.4 → 像：中间 4.2 m、两边 3.6 m（复用纪功柱的烘焙低模像，青铜暗色）。握拳的是中门两侧 4 根（史料「其中四根」，哪四根是我定的）。整座 ×HERO_SCALE 1.4（同纪功柱等比放大：占地是我在底账框里假设的，不是底账要素）→ 女儿墙顶 32.8 m、含像 39.6 m、宽 39.5 m。朝向：像面朝西（城外来的人先看见），同纪功柱。
4. **东门**：底账只写了西门 → 东口不做凯旋门，做一座柱廊门楼（两个方墩 + 一个拱 + 两面三角山花），宽 14 px，跨在 Mese 出口上。
5. **南北拱门**：小街 c（x=1444）被广场吃掉，但它两头的街还在 → 南北两翼外墙在那里各开一个 3.2 m 的拱门，柱廊不断。
6. **施工**：57–58 年 = 一圈木桩 + 拉绳（院边和外墙两道线）、整个框翻成土（盖住 streets 从 57 年就铺上的广场石板，见「剩下的差」）、6 堆石料；
   59 = 铺地（土去掉）、台基 + 外墙起到下层 45%、内外两排脚手架；凯旋门内墩的束柱先立、外墩只有墩座、一圈脚手架；60 = 凯旋门完工、下层墙到檐、下层柱立起；
   61 = 下层檐 + 二层楼板、上层墙到一半；62 = 上层柱 + 栏板；63 = 上层檐 + 椽子（没铺瓦）；64 = 铺瓦、压顶、门楼山花，完工。（59 / 60 / 64 是底账的，中间几年怎么分是我定的）
7. **比例尺**：1 页面像素 ≈ 0.84 m（同前两座）；参考图里的拉丁题字是生成图自己加的，模型里题额只做凸起的条，不写字。

## 怎么做的（全部在 `docs/living/nodes/nangang/3d/landmarks/`）

| 部件 | 文件 | 做法 |
|---|---|---|
| 整座 | `forum.js` | 四翼各一个坐标架 P(s,d)（s 顺翼、d 离开院子），N/S 翼占满长边、两头封端墙，E/W 翼夹在中间；门洞把一翼切成几段，每段 ≤ 30 px 按 `ctx.footing` 落地（地坪 = max、台基到 min−0.6，`ctx.foot` 登记）；柱位按整翼统一等分（角上让给角墩），每段只取自己那几根 |
| 几何小工具 | `forum.js` 的 `GB` / `boxF` / `prism` / `wallShape` | `GB` 按「朝外方向」自动定绕序（不怕左右手）；`prism` 把 (a,y) 剖面沿任意方向拉成线脚 / 檐部 / 山花；`wallShape` = 带洞的 `Shape` 挤出成墙再搬进世界坐标；`splitInner` 把朝院子那面拆给内墙材质 |
| 柱子 | `forum.js` 的 `colGeo` + `kit/lathe.js` + `kit/acanthus.js` | 下层 / 上层各一个 InstancedMesh（实例在世界坐标，`frustumCulled=false`），近档 10 棱 + 科林斯远档柱头，远档 6 棱 + 方块柱头 |
| 棍棒束柱 | **新** `kit/club.js` | 下细上粗的旋转体 + 5 圈 20 个「砍掉的枝杈」短桩 + 柱头下一道握拳（箍 + 4 根指节）+ 科林斯远档柱头；泪滴 / 树皮纹在 `clubTex` 的法线贴图里 |
| 凯旋门 | `forum.js` 的 `archGroup` | 米制局部坐标、整组 ×K×1.4；拱身 = 一整片 `Shape`（底边挖三个半圆）挤 4 m 深 → 筒拱自己出来；拱圈线脚、拱心石、檐口（`prism`）、女儿墙 + 浮雕板（`atticTex`）、壁柱 |
| 补光 | **新** `kit/fill.js` | 从宁芙殿的 `withFill` 搬出来的通用版（宁芙殿自己那份没改，机位 6 逐像素不变）；所有大理石 / 墙 / 柱材质都挂 |
| 贴图 | `forum.js` 的 `marbleTex` / `wallTex` / `roofTex` / `colTex` / `clubTex` / `atticTex` | `kit/relief.js` 出法线 + 反照率，世界 UV（按法线主轴投影，一张 = 4.8 m） |
| 模块壳 | `index.js` | **一个 id 可以挂几个文件**（纪功柱和广场同是 forum_theodosius）；`selfFoot` 的文件自己落地；`__landmarkStats` 的键 = `key`（广场是 `forum_theodosius:forum`） |
| 占位 | `buildings.js` 的 `PARTS.forum` | 单层柱廊占位整段删掉；`LM_SCALE.forum` 搬成 `forum.js` 的 `PORTICO_SCALE`。它推进 `ctx._cols` 的柱子排在所有民居之后、后面的地标不推柱子 → 不用留空实例（机位 1–4、6 逐像素证明了） |
| 比形钩子 | `forum.js` | `?lmmask=1&lmonly=arch` 只出凯旋门（柱廊、门、角墩不建），给 silhouette 用 |
