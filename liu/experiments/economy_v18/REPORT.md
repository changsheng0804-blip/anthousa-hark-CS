## 1 改了什么（全部是假设，触发条件只看到港量）

触发条件：当年到港 < `res_trig` 80% × 基线 600 船。基准 ×1.0 和 ×1.5 一年也不触发，所以**平年的户层流和 v17 逐行相同**，AF70 各项指标与 v17 完全一致（下面 §4）。

1. **储备库**（新机构 `官:储备库`；新流 `储备金存入(关税截留)`）
   - 平年：本该上解皇库的关税（2/3 份）截留 15% 存在城里，库存上限 20,000，满了就全额上解。基准下 AF40–44 每年存 3,600，AF45 达到 20,000，之后不再存。**不会无限积累**。这笔钱本来就要流出城外，所以截留对平年的城内经济没有任何影响。
   - 触发年：皇帝蠲免本城的关税上解，**全额转入储备库**，同样受 20,000 上限约束；当年最多动用库存的 60%。
   - 动用顺序：①转业：短工、近岸渔业 → ②公役扩招 → ③平价 / 救济粮 → ④房税代缴。
2. **港口工人冲击转业**（仅触发年；都在常年公役之后、码头零工之前）
   - ① 手工 / 营造短工（新流 `工钱:短工(转业)`，雇主付）：剩余的无工者不限距离，补区内因距离没人补的工位，上限为工人的 8%。
   - ② 近岸渔业（新流 `收购渔获(储备库→近岸渔工)`）：步行到港口 ≤R_walk 的无工者，每户渔户最多带 2 人；储备库按 0.6 × 工钱收购渔获，充作平价粮。
   - ③ 营造公役扩招（新流 `公役工钱(储备库扩招)`）：常年公役加扩招合计 ≤ 工人的 45%，工钱用当年的出清工钱。
   - 救济（新流 `救济(平价粮)`）：无工户 2.0，只有码头零工的户 1.0，预算不足时按比例缩减。房税代缴（新流 `房税减免(储备库代缴)`）：没有正式工位的自住房主，当年房税由储备库返还。房税照收，31/31 对账不变。
3. **借贷**（仅触发年）
   - 放宽额度：每个放贷人的笔数上限 4 → 8，放贷后自留 2.0 → 1.0，可以向多家分别借（亲属 → 同行会最近 5 户 → 坊长 → 同区 v2 放债人最近 8 户 → 盈余户最近 8 户）。
   - 官贷（借贷来源 `官贷(坊长代发)`）：借不到或借不足的亏空户，由坊长代城市长官库放贷。每户每年 ≤ 4.0、官欠余额 ≤ 8.0，总额 ≤（长官库 − 5,000）× 30%，**次年起分 3 年等额还**（`还款` → 城市长官库，坊长代收）。借户迁走或房子拆掉，官欠核销。
4. **阿里乌寄存**：只做核查，不加返还规则（见 §7）。

## 8 已知问题 / 推不出

- **蠲免是这套缓冲的大头**。骤降一年靠的是存下的 20,000；但到港 ×0.5 持续 31 年时，靠的是皇帝每年全额蠲免关税上解。Joshua the Stylite 记载过 Anastasius 为 Edessa 一带蠲税、拨钱赈济（见 §10），但那是土地税 / 赈款，不是关税，也不是常年蠲免。把它当成长期萧条的常规机制是本轮的强假设。不蠲免（组 1）时，×0.5 的无人借仍有 4,969。
- **×0.5 的 v18 贫困率（9.9%）低于 ×1.0（10.8%）**：45% 的工人领公役工钱 3.0，正好等于贫困线。这说明平年的贫困主要来自常年 11.8% 的失业，而城市长官库平时并不吸收这部分人。
- **AF66 余震**：区内雇主按上年营收雇人，骤降后第二年失业 22.5%，没有缓冲。可以改的方向（本轮已用完 6 组，没做）：触发后多延一年，或者按「上年营收 / 基线」触发。
- **净收入贫困率 13.0% 没降**：平年不触发，户层流和 v17 相同。要降到 ≤11%，需要平年的常设机制，比如储备库满额后，截留部分转作常年公役（每年约 3,600，约 1,200 个公役岗位）。粗算会把失业压到 5% 以下，越出 5–15% 的目标区间，所以本轮没做。
- **短工通道在本模型里无效**（各档都是 0 人）：骤降年区内工位已被跨区找活补满。
- 官贷的规模很小（AF65 186 户、478 份），亏空主要靠放宽后的亲属分借来补（亲属 2,617 笔）。官贷预算或上限再放宽也没有用（组 3、5）。
- 码头零工和公役只看到港量，骤降期间的工钱一直贴在下限 3.0（v17 已是如此）。
- 体面户 310 户、手工铺 302 户收入低于线，本轮没动（同 v17）。

## 9 守恒与对账（全部通过 → 已提交）

- 基准 31 年每类流「付 = 收」，最大误差 1.87 × 10⁻⁸。货币年变化 = 外部流入 − 外部流出 − 随户注销的欠账，最大误差 1.86 × 10⁻⁹。×0.5 / ×1.5 分别为 1.1 × 10⁻⁹ / 1.3 × 10⁻⁹。
- 户数 = 账本在立房屋、口粮到户 = food_cap、房税 = 0.5 × 账本房屋，三档都是 31/31。
- 5 个事件增量 == 重建 5/5（AF48 火灾、AF55 新粮仓、AF57 新市场、AF62 新街、AF65 到港骤降）。
- `flows_AF40/50/60/70.json.gz` = 0.78 / 1.19 / 1.32 / 1.44 MB，都 < 3 MB。工人户的 `work` 新增 `转业:短工`、`转业:渔` 两种状态；扩招的公役记为 `公役`。
