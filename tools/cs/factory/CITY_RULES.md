# 全城生长规则 · 推演稿（cs31 前，未实施）

## 分层：每层只读上层，不写回
L0 地形：陆/水掩膜、岸线（底账推得）
L1 骨架（底账原样，永不生成）：城墙、城门、19 条大道、水道、港口、广场、地标，带建/毁年份
L2 接驳：每个城门/港口/广场/地标入口必须有街连到最近大道（吸引点）
L3 街：从大道分叉。方向场=附近大道切向按距离加权，近水贴岸，近墙平行墙。间距随房屋密度。遇街/墙/水/地标即 T 形止。
L4 巷：大于阈值的街块内切巷；旧区允许死巷、弯
L5 地块：沿街切，面宽/进深随功能（港区窄深，广场区宽）
L6 房屋：底账房屋落到最近临街地块；底账决定区/年，生成只管呈现
L7 外观：全城统一调色基线，按功能/年代小偏移；画作由掩膜生成

## 组合规则
1 单向依赖：下层读上层，底账在最上，永不被改
2 全城一次长出，街区只裁窗口；随机种子按世界格子，不按街区
3 时间是维度：每条街/巷/地块带起止年（首户入住、所属大道建成、地标覆盖、火灾）
4 冲突优先级：水>墙>地标>大道>街>巷>地块>房屋
5 参数一张表全城共用；差异只来自输入（密度、年代、离大道/岸距离、功能）；配方只许放框与心跳，禁街网参数
6 局部重算：底账变化只重算受影响格子

## 规则即检查
- 邻区接缝：共享边上街端点一一对应
- 方向一致：街与最近大道夹角近 0/90°（旧区弯巷例外）
- 连通：每条街经图可达大道网
- 不越水、不穿墙
- 同分布：街距/街块大小是密度的函数，与街区名无关
- 时间单调：无底账原因不得消失又出现

## 已实施（cs31）
- L0–L3：tools/cs/factory/city_streets.py → city/streets.json（世界坐标，全城一次，约 3 秒）；预览 out/city_streets.jpg
- 方向场里大道之间取最近最粗的一条，不相加（两条垂直大道相加会抵消成 45° 乱街）；坡只在离大道远处起作用
- 地标盖起来前地皮上住过人的，不挡街（由街区按 cs29b 在盖成那年收掉）
- L4–L6 仍由 streets_ng.py 在窗口里做（地块、房屋、街的年份）
- 检查：tools/cs/check_citynet.py（一张网 / 顺着大道 / 无街区专用参数 / 同分布 / 接缝），accept.py 跑
- 未做：街的年份按框内房子算，框边上靠框外房子才开的街会晚开或不开（接缝阈值暂放 48 px）；L7 全城统一调色
