## 做了什么
- **船**：当年在用的每座栈桥恰好一条大船，贴栈桥一侧泊着（圆腹粮船两种涂装：深腹、鹅颈尾柱、主桅收帆、前斜桅、双舵桨、尾舱；窄长桨船：低舷、桨斜靠舷边）。摆放时逐点测：船身全在当年港池/海里、不压任何栈桥、不和别的船叠；22 座全部一次放下（fallbacks 0）。`tick` 里轻微起伏（still 模式 t 固定）。
- **小艇 / 驳船**：港池里和粮仓前水面沿岸泊着（驳船舱里堆麻袋），**另算，不计入「每座栈桥一条船」**。
- **踏轮吊车**：陆上码头岸沿（不上石堤），主臂朝水，吊着一包货；粮仓前 3 座，港区按栈桥数 /3。
- **货**：岸带（离水 1.5–10 像素，粮仓区 20）和粮仓门前（18 像素内）：麻袋金字塔、沿岸长溜麻袋、双耳罐（立排 + 卧垛）、木箱、草捆 / 布捆、手推车；岸沿系船桩。不进房子、不进地标、石堤上减半、不靠水的粮仓门前减半。
- **植物**：柏（两节锥 + 细干，高度同第 1 轮）、橄榄（歪干 + 几团灰绿冠）、园子树（第 1 轮没画，现画成矮干宽冠果树，一半挂果）、树脚灌木 0–2 丛、约三成园子树旁一架葡萄。灌木/葡萄架是装饰，位置由树位置 + `ctx.hsh` 推出，不新增「树」。
- 全部 InstancedMesh（每种部件一个）+ 顶点色 + instanceColor 微调；确定性（同代码同机位逐像素相同；60→20→60 来回拨后机位 4 逐像素相同）。

## match.py --against 之前 --skip props,flora（不过的几条，原因）
都是本模块的东西出现在别人的带里，不是改坏了别人的代码（props/flora 之外的文件一个没动）：
- 机位 1 water 带：边缘 +126%、L* −1.8 —— 港池里的船（美术圣经机位 1 要求「每个泊位都有船」）。
- 机位 1 buildings 带 +26.7%、机位 4 buildings 带 +139% / L* −2.1 —— 码头上的货、吊车（吊车高过地平线）、坡上树形。
- 机位 3 buildings+streets 带 +7.1% —— 主要是园子树 + 灌木（flora 单独归因见 `match_flora_attribution.json`，在第 0 步那棵树上量的：关掉 props、只换新 flora，机位 3 该带 +7.9%、机位 1 buildings 带 +16.7%）。
- 其余带（机位 2 全部、各机位天空、机位 3 水+地形带）完全不变。

## 要 core / 别的模块改的（建议，不是我改）
- **terrain / core**：码头岸是地面蒙版糊出来的一条 ~10 像素沙坡，不是竖直的码头石墙；货只能摆到坡顶。码头立墙（或把港池岸线蒙版锐化）会让机位 4、1 一下子像码头。
- **buildings**：栈桥是一块平板（顶 1.6）、石堤顶 3、粮仓是长盒子——吊车和货都按这些高度摆，buildings 改高度要告诉我（`reg` 里放 `pierTop`/`moleTop` 最好）。
- **water**：尤利安港有一半在 x > 1820（区外），水陆蒙版不覆盖那里；我自己用港池多边形判水。区外的水若要倒影/浪，water 也得用多边形。
- **crowd**：搬运工可以走我的货堆之间；货堆位置在 `ctx.reg.propsSite` 之外没导出，要的话我可以写 `reg.quaySlots`。
- 预算：props+flora 共 ≈ 62 万三角形；若 Mac 上吃紧，先砍港区（非粮仓区）的货堆密度，机位 4 不受影响。
