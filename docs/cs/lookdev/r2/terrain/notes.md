# 南港 3D · terrain · lookdev 第 2 轮第 1 波

——Hark（CS线）2026-10-20

## 做了什么
- **区外陆地**（`3d/terrain/outer.js`）：南港框外按真实地理铺陆地。海岸 = `data/land.geojson`（OSM，与节点流水线同源、同样开运算 r=22 去现代填海细条），高程 = `data/elev_grid20.json`（SRTM，与 `engine/terrain.elevation` 同一函数），高度公式同 core `ground()`。
  粗网格 LOD：框边 ±2.6–3.4 km 内 64 像素一格，外面 192 像素一格，只建碰到陆地的格；框边一圈顶点运行时用 `ctx.ground()` 取高，再加一圈 8 像素一段的裙边盖缝。新增约 3.3 万三角形。
- **地面材质**：区外专用贴图（2048 宽，逐像素算，不碰 core 的共享画布）：干草金 / 灰绿灌丛 / 裸土大斑块、按坡度的灌丛点和石灰岩露头、城外田块；
  城里按全城底账房屋（`docs/living/nodes/city/nodes.json`，24 像素格覆盖率 + 半数建成年份，跟 `ctx.year` 走）画「远看的屋顶色斑」，着色器按 `fwidth` 补近处 9×7 像素一户的瓦色和户缝、远处退回平均色。**不建任何房子**。
- **远岸环**：远平面 9000 像素以外的真实地物（王子群岛、Sivriada/Yassiada、亚洲岸卡德柯伊—马尔泰佩—卡尔塔尔—图兹拉、马尔马拉南岸萨曼勒山/阿尔穆特卢、乌卢达山、欧洲岸西段、北面台地）
  每 0.5° 一列存（最近岸距、扣地球曲率 k=7/6 的最高有效高度及其距离），画在一圈跟着相机走、半径 8300 的环上：按相机高度实时算真实仰角，所以任何机位都在对的地平线上。环下半圈是「远海裙」，颜色 = 远处被雾吃掉的海色，把海面平面被远平面截掉的地方补到真地平线。远岸点位是手填的近似值（±50 m / ±1 km 量级）。
- 区内原来的地面贴图和 4 像素网格**一个像素没改**。
- 烘焙：`docs/cs/lookdev/r2/terrain/bake_outer.py` → `3d/terrain/outer_data.js`（78 KB）。

**为什么 0.12–0.40 带够不着**：用机位 3 的相机做射线求交，这条带全部落在南港以南 1.6–5.2 km 的开阔马尔马拉海面上（东岸往东北拐出画面左缘，亚洲岸在方位 66°+，画面左缘是 52°），按真实地理没有陆地；而且 sky 的雾（1400–3800）把 3.8 km 以外全吃成雾色。真地平线在画面最上 1% 行内（相机俯 23°，半视角 22.5°），所以远岸只能出现在 sky 带的最上沿。这一带的边缘只能来自海面本身（water）或者改机位（core）。

## match.py --skip terrain（对基线）
- 机位 1 · 0.25–0.60 buildings：边缘 +34.7%、L* −2.5 —— 这条带里原来露出的海和天现在是区外陆地（terrain 自己的像素），是本轮要的变化。
- 机位 4 · 0.18–0.60 buildings：边缘 +5.4%（门槛 5%）—— 天际线后面多了一条框北的区外陆地，同上。
- 其余带全部 |ΔL*| < 1、边缘差 < 5%（机位 2 逐像素不变）。机位 3 天空带 L* −0.5（远岸剪影），边缘 0 → 0。

## 要 core / 别的模块做的
- **core**：远平面 9000 不用改（远岸和远海都在环里假出来了）。要让机位 3 读成参考图（地平线在 0.15、左边看到海岸和亚洲岸），得把机位 3 抬头（俯角 23° → 约 12–14°）、往左偏 15–20°，或者把 0.12–0.40 带的归属改成 water(+sky)。阴影相机只罩 ±1500，区外陆地不投影也不受影（sky 的事，可不改）。
- **sky**：远岸剪影的空气透视按真实距离、混向 `scene.fog.color`，不跟雾的远近走（否则雾 3.8 km 就把 16 km 的岛吃没了）；想调就在 build 里写 `ctx.reg.horizon.haze`（0.5–1.2 倍）。雾放远以后远海裙会自动跟上。
- **water**：远海裙默认海色 #5b8590；改了海色就在 build 里写 `ctx.reg.horizon.sea = THREE.Color`。
- **buildings**：区外城市现在只是地面上的屋顶色斑（全城底账驱动）；要立体的远景城，可以按同一份 `city/nodes.json` 做盒子+屋顶的远档。
