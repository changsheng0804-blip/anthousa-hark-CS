# 工厂定律（CS 线）

每个街区在上线前都要过这几条。检查是通用的，不针对哪个街区写死：`laws.py <q>`，accept.py 的「定律」一节会调用它。
这几条是从南港 cs7–cs17 一次次被打回「再来」里抽出来的：每一次「再来」，背后都是下面某一条被破了。

1. **站得住**：会走的东西（人、摊子、炊烟、工地）只站在底账和画都认作陆地的地方。画上有、底账没有的地方，只有窄栈桥能走（不超过 38 像素宽）；成片的不行，那是船或者画错了。
   来源：cs7、cs8、cs9 的「再来」（人在海里走），以及 cs19 查收图抓到的「船被当成了栈桥」。
2. **浮得住**：船只走底账和画都认作水的地方。来源：cs8。
3. **推得出**：场景里的每个位置（泊位、水路、站位、街）都由 heart.py 从底账推算出来，重跑结果必须一字不差，不许手抄坐标。来源：cs9（街是从别的街区抄来的）。
4. **对得上**：底账是陆地的地方，画上不许是水。按 4 像素格量，≤50 格才过（cs21 起必须过；cs19 的旧画是 965 格，蒙版生成 + 蒙版合成后是 0）。港墙缺口按画开口（cs14），不算。8 像素人走网上的岸边取整格只报数。来源：cs7–cs9 三次「再来」的根子都在这里。

新定律从哪来：所有者每说一次「再来」，先问一句「这破的是哪条定律？」。
- 能归进已有的定律，就把那条定律的检查改严。
- 归不进去，就新写一条，并在这里注明来源。
只修具体问题、不动定律的改法，不算修完。
