# water · lookdev 第 2 轮第 1 波

> 只动了 `docs/living/nodes/nangang/3d/water.js`。全量 4 机位渲染（不带 `only`），沙箱 SwiftShader，建城第 60 年。——Hark（CS线）2026-10-20

## 做了什么

- **海面**：仍是一块 20000² 平面（2 个三角形），材质换成 MeshPhong + `onBeforeCompile`：灯、阴影、雾、色调映射都走 three 自己的，不加灯，太阳读 `ctx.reg.sun`。
- **浪**：代码里算一张 256² 可平铺浪高图（整数波矢正弦和，相位用 `ctx.hsh`），五档尺度在世界 xz 上滚（大涌 331 px → 碎波 4 px，近处细浪横向拉长，远处按距离压平）；`tick(t)` 只移偏移量，still 模式同图。
- **倒影**：半分辨率平面镜面（镜像相机 + y≥−0.5 全局裁剪面，tick 里渲进 HalfFloat 渲染目标，浪法线扰动采样）。`quality=preview` 关掉，改用天色渐变。倒影随天空走：sky 把天空做暖，海面倒影跟着暖。
- **太阳**：Phong 尖高光（在阴影里会灭）+ 一条宽反光带（按 `reg.sun` 方向）。
- **深浅**：build 时在 4 px 格上按 core 蒙版同样的规则画一遍岸（陆地 + 当年石堤），做倒角距离场；G 通道 = 当年港池。港池里偏绿（#3e6748），外海偏蓝（#1d607c），外海近岸一圈也偏绿。只拿来上色，不决定哪里是水。
- **岸**：水线贴岸一圈压暗（湿痕/阴影），往外 1–6 px 一道被浪打碎的淡泡沫；地面贴图上沿真海岸和港池边画一道陆侧湿痕（跳过贴页边的那几段），石堤地皮描深边。
- **外海风带**：远处（>500 px）一条条细长平水带，反天光略亮，港池里没有。

## 机位 3 为什么没上去

那条带（画面上 12–40%）几乎全是远海 + 雾：从 440 m 高看，浪的细节被 mipmap 平均掉，雾把剩下的反差压平，Sobel(L*)>8 的像素靠水面本身做不出来（试过大块「平水斑」和细亮风带，边缘最多 0.006，而且看着像贴图错误，撤了）。参考图里这条带的边缘来自远岸山、对岸城和船。要上去靠：terrain 的区外陆地/远岸、sky 的雾和低太阳（太阳从左来时外海会有反光带）、props 的船。

## 要 core / 别人改的

- **core**：无硬需求。倒影用 `renderer.clippingPlanes`（全局）在 tick 里临时设、渲完还原；若 core 以后自己用全局裁剪面，告诉我。
- **sky**：天空现在是一块平灰蓝，倒影就是灰的，所以水偏灰；天空有渐变/暖色后水会自动变暖。太阳若移到画面左前方低处，机位 1 会出现亮反光带。
- **terrain**：区外陆地不在我的距离场里（只算页面内 1820×2048），区外的岸边没有泡沫/近岸绿；若 terrain 在 `reg` 里给一张区外陆地蒙版，我可以接上。
- **buildings**：石堤立面水线处的深色湿痕/藻带归 buildings（几何在它那儿）；水面这一侧我已压暗贴岸一圈。
