## A. 穿模

**怎么量**：`tools/cs/lookdev/ground_check.py --year 65`。独立于模块：按 terrain 网格同样的 4 px 三角插值自己采样地面（页面框外从场景里的 `terrain-outer` 网格重建；海面 y=0 以下算 0），
对每个占地（房子 / 地标部件 / 粮仓长仓 / 柱廊段 / 水道桥段 / 栈桥）的四角 + ≤2 px 网格比：
- 漏空（gap）：最低的墙 / 台基面比占地下最低的地面高 > 0.5 px；
- 埋（buried）：占地下最高的地面比地坪（墙、柱起点）高 > 0.5 px。
改后的数由模块登记（`ctx.foot`）；改前的按改前公式复算（房子 地坪 = elevPx(中心)+1.5、墙脚 −3；地标 elevPx(中心)+1.6、−3）。

**改了哪里**
- `3d/core.js`：`ctx.groundMesh(x,z)`（terrain 网格的三角插值；框外读 `reg.outerY`）、`ctx.footing(四角)` → `{min,max,mid}`、`ctx.foot()` 登记。每次重建、水陆蒙版更新后清缓存。
- `3d/terrain/outer.js`：导出 `heightAt`，build 时写 `reg.outerY`（区外网格同样的三角切法）。框外的 207 户、蓄水池、孤寡院以前按页面边上夹住的高度落地，现在落在画出来的区外地面上。
- `3d/arch/house.js`：地坪 = max(mid, max−0.45)（上坡那角最多埋 0.45 px），素面石灰石墙基伸到 min−0.6（最多 14 px）+ 顶面；原来那圈 3 px 的立面色墙脚删了。ht 从地坪量。
- `3d/buildings.js`：`block()` 不给 base 就自己落地 + 石台基（顶下两级台阶，再竖直下去）；广场四面柱廊按 ≤30 px 一段各自落地（坡上成阶梯），内侧柱列站在同段台基上（柱位、序号、色差和改前一样）；蓄水池穹顶按各自脚下最低处落；孤寡院四翼 + 中厅各自落地；栈桥只画在水上那段（沿桥 33 点、三条线都 < 2.1 才算水上）。
- `3d/arch/granary.js`：每座长仓自己落地，墙、扶壁、壁柱、山墙、木撑都伸到 min−0.6。
- `3d/arch/aqueduct.js`：桥墩底按桥身全宽下最低的网格地面（桥面高不变）。
- `3d/landmarks/index.js`：b = 占地下最高的网格地面（纪功柱用台阶外沿方块，宁芙殿用底账矩形），`F` 交给地标；登记。
- `3d/landmarks/nymphaeum.js`：台基、背墙、塔基、长槽、池栏全部伸到 −DEPTH（= 基面 − 占地最低地面 + 0.6 px ≈ 6.6 px ≈ 5.5 m；最少 3 m）；池栏外面做成一圈石阶（每级 0.38 × 0.42 m），坡下那侧读成台阶基座。
- `3d/flora.js`、`3d/crowd/stage.js`、`3d/props/site.js`：树 / 人 / 货改用 `groundMesh`；`3d/props.js`：±2.5 px 内高差 > 2.4（港池边 45° 沙坡）的地方不堆货（改前一层层悬空，见诊断 13），货堆三角形 419k → 362k。

**还不对的**
- 14 户在页面框角（x≈0 / ≈1820、z≈0），区内 4 px 网格和区外 64 px 网格在那里高差 20–80 px，墙基封顶 14 px 后底下仍漏空。要修得 terrain 把框边缝合，不是房子的事。
- 2 座栈桥（[1855,1288]、[1980,1310]）在框外，区外地形（OSM 海岸）在那里是陆地、底账是港池；整座在地里，没删（底账要素）。
- 港池岸还是 45° 沙坡（r2 已知的「硬码头」问题）：码头户现在是一座高墙基立在坡上（诊断 13），比悬空好，但真正的解法是竖直码头石墙。
- 民居墙基在陡街上最高 ≈2.5 px，临街柱廊铺面因此架高（诊断 12）——像奥斯蒂亚的高人行道，主人若觉得太高，可以把地坪改回 mid（代价：上坡后墙埋 ≤1.6 px）。
