# 规则预演 v0 · 用城自己的制度算关系（刘线，2026-10-12）

> 实验，不上线：街区页一字未改。弱关系每年现算、算完即丢；只有规则互相拉扯的「交叉点」存成强关系、写成故事。
> 本目录所有代码只读 `docs/living/xerolophos/`（页面家谱推演、facts_upstream 空间事实）和 `world.json`，不碰账本目录。

## 1. 一句话结论

**能放大，前提是分组规则只连「组内最近 k 户」，用不到的边改成「交叉时现查」。** 调参版从 85 栋房子的样本到干山 4,793 栋、再到全城 17,418 栋（合成人家）：每户每年的边数稳定在 8–11 条，每栋房子的交叉点稳定在 **1.46–1.48 个**，是线性增长。naive 版（同组两两全连）在干山就爆炸：每户每年 71 条边（样本 23 条），交叉点每栋 6.4 个，其中 85% 是同一种「同水异粮」。头部交叉点到了干山、全城也还有戏（4–6 个模式叠在同一对人家身上），但**骨架开始重复**：头部多是「同街同行两户：一家有房一家租、学徒、火后对头」这一个形状。

## 3. 规则清单（13 条，`rules.py`，参数全在 `rules.json`）

每条是一个函数 `rule(户, 年, ctx) → [(甲, 乙, 类型, 备注)]`。

**基础五条**
1. **同一口水**：每户每年喝最近的井（140px 内、井已建成）或蓄水池（420px 内）；同一口水的人家各连最近 4 户。附「运水人与主顾」：离水 >160px 的人家由 260px 内的运水人挑水上门，每个运水人至多 12 户。
2. **面包跟着房子走**：有房户（见假设 A）在最近的炉/面包台阶同排领君士坦丁的房屋面包，各连最近 3 户；租户没有面包。
3. **信仰分线**：90px 内同派最近 3 户同堂；51 年后阿里乌派那条边记作「同出城门」。
4. **同乡带同乡**：外地来的户，投奔搬来时 300px 内早 1–8 年来的最近同乡（链式移民）。
5. **同行聚街**：同街同行当，各连最近 3 户。

**经济**
6. **房东与租户**：租户向同街住得最久的有房户租房，每个房东至多 6 家（假设 B）。
7. **借贷与债**：灾年里有丧事 / 缺男丁 / 人口 ≥6 的租户，向 200px 内有房的面包师或酒馆老板借粮，每个债主至多 4 家，债拖 4 年（假设 C）。
8. **工钱与学徒**：没有成年男人的人家，12–15 岁的儿子跟 300px 内最近的同行师傅（没有同行就跟最近的师傅）。
9. **同行竞争**：一条街上同行多过街区容量（市集 4、铺面 3、其他 2），80px 内最近的同行就是对头。

**政治体制**
10. **恩主与门客**：体面人家街区的户，或住满 25 年且 ≥5 口的有房户，罩着 250px 内缺男丁 / 有丧 / 刚来 3 年内的租户；同派优先，每个恩主至多 5 家（假设 D）。
11. **教会层级**：执事的施舍只给本派缺男丁人家。尼西亚派 49 年起有阿纳斯塔西娅；阿里乌派 51 年前有城里的教堂，51–63 年没有，64 年起有城门外砖堂；65 年起寡妇孤儿之家不分派（年份全来自账本）。
12. **官府**：拆房让路（账本：54 年修运水人蓄水池拆 17 座房，干山页正好 17 栋 `destroyed=54`）；修蓄水池凑铜板（账本：54 年运水人，62 年上坡人家）；57 年修狄奥多西广场按街征工，每街 2 户（**假设 E**）。
13. **军营**：兵营坊里或城门兵营 220px 内的人家，以及有儿子「去当了兵」的人家（页面推演事件），都连到兵营。

### 账本里没有、只能推的量（单列的假设）
- **A 有房/租户**：账本只说干山「建城 42 年划成新区……多是新来的穷人」。设：这栋房子的第一户、且 41 年前就住进来的算有房；42 年后来的新户、住进旧房的后来户都算租户。干山 AF55 有房 2,350 户 / 租户 1,878 户。（第一版用「首户都有房」，结果 90% 有房、样本里一笔债都借不出来，故改。）
- **B 房东是谁**：同街住得最久的有房户。
- **C 灾年 / 粮价**：账本没有粮价。用页面推演的死亡率代：高于 AF40–70 均值 + 1 个标准差的年份。干山推出 **45、51** 两年；全城（合成）只推出 44 年，所以全城 AF50–70 窗口里一笔债都没有。51 年只比均值高 0.003，几乎是噪声——这是最弱的一条假设。
- **D 恩主**的门槛（25 年、5 口）。
- **E 57 年征工**：账本只记了狄奥多西广场和拆 29 座房，征工是假设。原题里的「修水渠征工落在运水人家」与账本相反——54、62 两座蓄水池是运水人和上坡人家**自己凑铜板**修的，所以改为「凑铜板 / 拆房 / 征工落在运水人家」。
- 君士坦丁的房屋面包配给本身是史实，但账本里没有这条，属于所有者给定的制度。
- 页面推演的 `MAXY=60`：60 年以后不再有出生、婚嫁、新搬来的人家，**AF61–70 只剩老去和死去**，户数逐年下降（干山 4,383 → 4,183）。为了不改动页面的家谱（改 MAXY 会改变整条随机序列），本轮不动它。

## 4. 交叉点（`cross.py`）

**冲突模式**（同一对人家、同一年同时成立才算命中）：

| 模式 | 条件 |
|---|---|
| 同乡异信 | 同乡链 + 一边阿里乌派一边尼西亚派 + 51 年以后 |
| 同水异粮 | 同一口水 + 一家有房有面包、一家租房没面包 + 没面包那家当年有丧或缺男丁 |
| 火后同行对头 | 同行对头 + 其中一家是 48–50 年搬来的（南港大火之后） |
| 正统房东·阿里乌派租户 | 房东尼西亚派、租户阿里乌派、51 年以后 |
| 债主欠债同街 | 债 + 同一条街 |
| 恩主门客异信 | 恩主和门客不同派 |
| 房东兼债主/恩主 | 同一对人家既是房东–租户，又是债主或恩主 |
| 同井施舍分线 | 同一口水、两家都缺男丁，一家领得到本派施舍、一家领不到 |
| 学徒拜异派师傅 | 学徒和师傅不同派 |
| 运水人摊上公家的事（单户×机构） | 运水人家被拆房 / 被征工，或缺男丁、有丧那年还要凑铜板 |
| 儿子当兵·家里无男丁无施舍（单户×机构） | 有儿子当了兵、家里没有成年男人，也领不到施舍 |

同一对人家身上命中的所有模式合成**一条强关系**。**戏剧性分数** = 涉及的规则数（「同一口水」「同行聚街」只说明是邻居，算半条）+ 1.5 ×（模式数 − 1）+ 0.25 × 持续年数（≤8）+ 与账本大事的贴近度（大事强度 × e^−|年差|，主题对得上才算满分）+ 当事人家里的账本事（有丧 +1、房子被拆 +1.5、缺男丁 +0.5）+ 转折（在窗口里开始、结束各 +0.5）。选故事时贪心挑：同一户只用一次，同一骨架最多两个。

**调参记录**：v0a 的「同乡异信」只要信仰不同就算，样本里占 60/162，头部全是两户邻居的静态关系；v0b 收窄到「51 年后阿里乌派对尼西亚派」：样本 60→31，干山 2,935→1,357，全城 10,078→4,647。

## 5. 故事（`stories.json`，8 篇全部过核对）

`check_stories.py` 逐条核对每篇的 claims：人在那年在家 / 那年死 / 那年几岁 / 那年出嫁或嫁进来；户在那年住哪条街、几号门牌、有房还是租、几个孩子、缺不缺男丁、什么行当籍贯信仰、哪年搬来；规则边那年确实算得出来（含方向），以及某年确实「没有」某条边；喝的是哪口水；灾年是规则推出来的；账本年份确有大事。正文反向扫描：出现的两位数年份、人名、街名、行当、籍贯、信仰都必须被 claims 核对过；像街名却不在底账里的「某某巷/街」报错；每篇 3–4 句。故意把一处年份改错、添一条假街名，核对会报出来（已试）。

两篇原文：

> **#1 同水异粮 + 房东兼恩主**　56 年科斯马斯一死，浴场后街五号就剩欧朵西娅带着四个孩子守那间小酒馆，房子是租的，领面包的名册上没有她家。同在水池街口那口井打水的面包师斯特凡家有房有面包，把她家罩了下来，第二年起连房东也是他。欧朵西娅没搬走，酒馆照开，熬到 65 年卢基乌斯满了十六，她家才不再是斯特凡的门客。66 年斯特凡去世，同一年欧朵西娅的小女儿尤菲米娅也没了，才十岁。

> **#3 同乡异信 + 同井施舍分线**　城墙根街七号的欧瑟比乌斯两口子 49 年从安条克来，第二年同乡以撒一家搬进同街五号，两家在城墙根街那口井打水。52 年欧瑟比乌斯死了，十九岁的佐伊抱着刚出生的巴尔巴拉守寡；58 年以撒也死了，阿格尼丝带着六个孩子。阿格尼丝是尼西亚派，阿纳斯塔西娅的执事有她一份施舍，佐伊是阿里乌派，城里的教堂早不归她们了——同一口井边，一家领得到，一家领不到。到 65 年寡妇孤儿之家盖起来不分派，阿格尼丝却在那年死了。

（其余 6 篇见 `stories.json`。故事里「选择」那一步只写规则本身蕴含的决定——送儿子去学手艺、灾年开口借粮、不搬走——不替人编动机。）

- **爆炸的是「同一口水」「面包同排」「信仰」「同行同街」四条全连的分组规则**：一口井、一座炉、一条长街的户数随密度上涨，两两成边就是平方增长；「同水异粮」直接继承了这份平方。改成「组内最近 k 户」（4 / 3 / 3 / 3）后线性。
- **lazy 版**（`rules_lazy.json`）：运水人 / 信仰 / 面包 / 同行四类边不再逐年全量算——交叉模式只用到它们背后的户属性（行当、信仰、有没有房、在哪条街）。干山边数再降 58%，时间 28 s → 18 s，**交叉点一个不差（7,035 = 7,035）**；分数略降，因为少了「同行聚街」那半条规则的加分。全城 lazy：边 1,479,533，规则 94 s CPU，交叉点同样 25,494。

### 能不能放大
**能。** 理由：
1. 交叉点随人口近线性：每栋 1.48 → 1.47 → 1.46；边也是线性（每户每年 8–11 条），没有一条调参后的规则是平方增长的。
2. 头部仍有戏：干山第 1 名（20 分）是城墙根街的两户运水人——比提尼亚同乡，一家尼西亚派、45 年起守寡的阿格尼丝当家，一家「还拜旧神」、48 年大火后才搬来、51 年当家的彼得就死了——四个模式叠在一起（同井施舍分线、同水异粮、学徒拜异派师傅、火后同行对头）；高分段占比随规模从 2.4% 升到 5%，大城里更容易出现多规则叠加。
3. 但**重复骨架是真问题**：干山最大的五个骨架（同水异粮 | 异行 | 阿里乌派对别派 1,107 个、同乡异信 1,076、同水异粮 | 两边都阿里乌派 723、学徒拜异派师傅 | 同行 536、正统房东·阿里乌派租户 514）占全部交叉点的 56%；头部前 100 名里「同水异粮 + 学徒拜异派师傅 + 火后同行对头 | 同行」一个骨架就占 12 个。全城（合成）骨架数（104）反而比干山（124）少：规模大了，形状没变多。→ 选故事必须按骨架去重（本轮已做：同一骨架最多 2 个），下一步要让骨架里带上「想要」和账本大事（PEOPLE.md 第 1 条），而不是只看规则组合。

## 7. 哪条规则最出戏 / 最没用
- **最出戏：房东与租户 + 恩主与门客 + 借贷与债（经济/政治那几条），以及教会施舍。** 干山前 8 名每一对都带房东、债或学徒；「同井施舍分线」把账本里的 51 年（阿里乌派被请出教堂）和 65 年（寡妇孤儿之家）直接落到两户人家身上，故事 #3 就是这样来的。
- **最没用（最贵又不出戏）：运水人与主顾。** 干山 13.9 万条边（占 15%），却只有「运水人摊上公家的事」一个单户模式用到它，而那个模式只看户属性、根本用不到这条边。其次是**同行聚街**（15 万条，纯背景，几乎每对邻居都有）和**军营**（1.4 万条边，只出了 86 个交叉点，样本里 2 个）。这三条更适合只在交叉时现查。
- **虚高：工钱与学徒。** 「学徒拜异派师傅」出现在大多数头部骨架里，但「异派」只是随机信仰分布（55/25/20）带来的，不是制度冲突；它让分数虚高、骨架重复。下一版应降权，或要求账本事件（51 年后才算）。
- **官府-征工（假设）**：干山每年最多 140 条，只能和运水人碰出很少的交叉点，而且建立在假设上；凑铜板 / 拆房那两半有账本支撑，留着。

## 8. 已知问题
1. **AF61–70 只有老去**（页面 MAXY=60）：没有新生儿、婚嫁、新户，户数下降、施舍和学徒边数自然归零，后十年的交叉点偏少、偏「死人多」。
2. **灾年是噪声**：死亡率推出的 45、51 年只比均值高一点；48 年南港大火在页面推演里不死人，所以不是灾年；全城没推出窗口内的灾年，债为 0。需要账本给出粮价 / 饥荒事件，或改成从「火灾搬来户比例、粮仓建成年」推。
3. **房东分配对边界敏感**：故事 #4 的「房东」在样本闭合世界里是隔壁 133 号以撒家，用整个干山核对（`SCOPE=xero python3 check_stories.py`）时，那年北梅塞路住得最久的有房户换成了别家，这一条不过（其余 7 篇在整个干山也全过，#4 的恩主、学徒两条边也成立）。下一版房东改成「同街最近的有房户」，并把强关系一旦写进故事就入账固定。
4. **138 栋房子没有街名**（facts_upstream 原有问题），故事 #2、#8 里这几户只写路口的炉/井，不写街名。
5. 打分里「房东兼债主/恩主」这个模式的基础规则把「借贷与债」固定算进去，即使那一对实际只有恩主没有债（#1、#4 的规则数因此多算 1 条）。
6. 全城是**合成人家 + 合成街/井/炉**，只能说明数量级和增长曲线，不能用来写故事。
7. 「有房 = 41 年前住进的首户」是最大的假设，决定了面包、房东、债、恩主四条规则的走向。
