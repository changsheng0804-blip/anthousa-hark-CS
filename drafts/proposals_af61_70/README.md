# 干山上的请愿 · 建城 61–70 年（草案，刘线 liu3）

**这是草案，不是正史。** 不在 `proposals/` 里，引擎不会读到；`proposals/`、`rules/`、`chronicle/`、`engine/`、`data/`、`i18n/` 一个字没改。
要采用哪一份，由所有者（或下一次心跳推进 61–70 年时）把它的 actions 贴进 `proposals/make_era_0061.py`，作为「平民」那一份。

思路：城不是作者画出来的，而是从居民的处境里长出来。先数清楚克塞罗洛福斯（干山）的人在为什么犯愁，再让他们自己提要求，交给引擎裁决。

## 文件
| 文件 | 是什么 |
|---|---|
| `pressures.json` | `tools/petitions.py --stats` 的输出：每种压力的户数、户号、引文；家谱逐年推演（50–70 年）；底账数字 |
| `make_petitions.py` | 生成下面五份请愿（与 `proposals/make_era_0051.py` 同样的 B/rect 写法；不 import make_eras_v3，因为它会顺手重写 era_0000/0001） |
| `petition_1_water.json` … `petition_5_widow.json` | 五份请愿，格式与 `proposals/era_NNNN.json` 完全一样：`era` / `actions` / `review` |
| `petitions_all.json` | 五份合在一起，作为一个十年的平民提案 |
| `i18n_additions.json` | 引擎检查要求的中文名/标注（未写进 `i18n/`） |
| `trial_results.json` | 引擎试跑结果（见下） |

## 证据从哪来
- **街坊闲话**：`docs/living/xerolophos/voices.json` 385 户（原 371 + 本轮补写 14）。按话题的关键词数「有多少户提到」，再用更窄的「说得最直白」的词数一遍（下表括号里的数）。
- **家谱推演**：页面自己的 `household()`（`tools/export_households.js`），这一角 4,383 户、23,912 人（建城 60 年）。
- **底账**：`world.json`（`engine/build_all.py` 重建），建城 60 年全城 149,193 人，粮食上限 193,202，供水上限 188,000。

| 压力 | 闲话里提到的户数（说得直白的） | 家谱 / 底账 |
|---|---|---|
| 没了当家的（寡妇、孤儿撑门户） | 102（60） | 60 年这一角 615 户没有成年男人、却有 14 岁以下的孩子（约七户里一户） |
| 孩子没留住 | 90（62） | 60 年这一角 96 个婴儿死在周岁前 |
| 粮与面包 | 63（14） | 底账：粮食上限 193,202 > 人口，**粮在账上不是瓶颈**；街坊愁的是价钱和嘴多，引擎不管价钱 → 没有写成请愿 |
| 大火以后（烧掉的家、搬上山） | 59（21） | 家谱：241 户「原来的家烧在了南港大火里」，856 户「收留过一个远亲」 |
| 屋里挤 | 56（15） | 60 年 469 户十人以上同屋，473 户两代媳妇同屋；61–70 年还有 3,373 个儿子在父母屋里满 18 岁。底账：61–70 年空推一个十年，全城只长得出 580 栋房子——**地已经满了** |
| 缺水 | 38（14） | 742 户运水人供这一角 23,912 人（每户运水人家对 32 人）；底账供水上限 188,000，离人口还有余量 |
| 信仰 | 22（14） | 2,435 户（55.6%）是阿里乌派，51 年起被请出城里所有教堂，唯一的礼拜处是城墙外一个木头院子 |
| 抢生意 | 18（7） | 772 户面包师、755 户陶匠……挤在同一片坡上 |

注意：补写的 14 户是我这一轮写的（都是家谱里南港大火后上山的人家），会让「缺水」「信仰」各多 4–6 户。补写之前的数是：缺水 34（12）、信仰 16（9）、大火 53（17）、屋里挤 57（14）。
家谱只生到建城 60 年：61 年以后没有新出生、没有新搬来的人家，所以 61–70 年的家谱数字是下限。

## 五份请愿
（数字是引擎在 `/tmp` 临时副本里跑 `build_all` + `check` 的结果；基线 = 同一个十年什么都不提。基线：70 年 154,413 人、17,157 栋房子、本十年新长 580 栋、供水 188,000、粮食 193,202；这一角克塞罗洛福斯区 790 栋。61–70 年骰子没有掷出火灾、地震、瘟疫，所以每份试跑的天灾都一样，可以直接比。）

1. **坡上的第二口池子**（缺水）：运水人石阶 `r_carriers` + 运水人第二蓄水池 `cistern_slope`（半山腰，440,425）。
   证据：14 户直白地说水（如 16872「这城里水比粮贵」、17540「这里的池子浅，可人多」），742 户运水人对 23,912 人。
   引擎：第 1 轮驳回（池子离路超过 25 单位）→ 把石阶排在池子前面，第 2 轮通过。供水 188,000 → **203,000**；但人口 **154,413 → 153,918（−495）**：拆了 55 栋房子（石阶 40、池子 15），而城里没有空地补长。水在账上不是瓶颈。
2. **城墙外的新街坊**（屋里挤）：新来人巷 `r_exo` + 城墙外新区 `d_exokionion`（奠基者城门外，梅塞大道两侧）。
   证据：15 户直白地说挤（17008「酒馆里已经挤不下了」），469 户十人以上同屋，3,373 个儿子在 61–70 年成年。
   引擎：一次通过。本十年新长房子 580 → **1,144**，其中城墙外 534 栋；人口 **+5,076（159,489）**。五份里唯一真正让城长大的一份。
3. **横穿干山的防火巷**（大火以后）：干山防火巷 `r_firebreak_hill`，从梅塞大道斜穿干山到莫德斯图斯路，宽 2。
   证据：21 户直白地说火后漂泊（11627「在城里赁屋住了十年」、14014），家谱 241 户被南港大火烧出来。
   引擎：第 1 轮驳回（id `r_firebreak` 已被 22 年的「余烬街」用了）→ 改名，第 2 轮通过。代价很重：**拆 155 栋房子**，克塞罗洛福斯区 790 → 666 栋，人口 −1,350。
4. **城外的砖礼拜堂**（信仰）：城门外阿里乌派礼拜堂 `church_arian_brick`（砖砌巴西利卡，civic，ornament 1）。
   证据：12391「阿里乌派的神父不肯进城，连给孩子祈祷都要走到城门外去」；2,435 户阿里乌派。
   引擎：一次通过，不拆房、不动人口和供水粮食，只多了一座建筑。
5. **孤寡院**（没了当家的）：干山孤寡院 `xenon_xerolophos`（monastery，domestic）。
   证据：60 户直白地说当家的死了以后谁撑着（12015「玛尔塔接过了酒馆，八个孩子一个都没少」），615 户无成年男人带小孩。
   引擎：一次通过；拆 15 栋房子，人口 −135。

**五份合起来**（`petitions_all.json`）：七项全部通过，`check` 全过。70 年 **157,410 人（比基线 +2,997）**、17,490 栋房子、本十年新长 1,136 栋、供水 **203,000**、粮食 193,202 不变；共拆 223 栋（防火巷 155、石阶 40、池子 15、孤寡院 13）；干山本身 790 → **607** 栋，城墙外新长 537 栋。
一句话：**干山上的人要的东西，在账上的结果是：山上变空、变安全、水变多，人搬到城墙外去。** 这和真实的城很像（城墙外的新区，后来被狄奥多西城墙圈进来）。

## 要所有者拍板的
- 采用哪几份。防火巷拆 155 栋是否值得；如果嫌重，可以收窄或只修下半段。
- 「粮价」是街坊第三多的话题，但引擎只算粮食总量、不算价钱。要让它进账，需要改规则（方向性变化，先问）。
- 正式推进时还要写中英编年史 `chronicle/61_70.md`、把 `i18n_additions.json` 合进 `i18n/i18n.json`——这些属于正史，这一轮没有动。
