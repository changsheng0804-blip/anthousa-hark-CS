# surface_v22 · 经济层 → 城市表面层

经济层（economy_v21 逐户流）是暗线；这一版把它翻成街上看得见的东西：房子修没修、铺子开没开、门口冒不冒烟、街上挤不挤、教堂门口排多长的施舍队、码头几条船几个脚夫、仓库满还是空。只做映射，不改经济模型，不写故事。——Hark（刘线）

运行：`python3 shock_run.py`（约 46 s，按路径只读载入 economy_v21，跑 AF65 到港 ×0.3 骤降路径，AF64/65/66 逐户流写进 `.shock/`，不入库）→ `python3 surface.py`（约 6 s）。
产出：`docs/living/xerolophos/surface_AF{40,50,60,65,70}.json`（每个 0.27–0.46 MB）、本目录 `results.json`（分布、匹配率、骤降对照、街道门槛、设施坐标）。
页面：`docs/living/xerolophos/index.html` 右上「表面」开关（BUILD liu5）。

## 1 房屋怎么对上

- 页面画的是干山 4,831 栋房（`houses.json`：`[id, 片区, 建成年, 拆毁年, 多边形]`），门牌来自 `facts_upstream/addr.json`（上游街名索引 + 号）。
- 页面房屋 id **就是**账本房屋 id：`2604` ↔ economy_v21 `households.house = "h2604"`、yamen_v13 户籍 `房屋id = "h2604"`。v13 门牌（`路·east 146号` 这种账本键）不用来匹配，页面门牌照旧由 addr.json 给。一户一房：v21 每户一栋房，`house` 列不重复。
- 坐标核对：用 4,831 栋逐栋 id 拟合 页面→账本仿射，残差 RMS 0.014、p95 0.025 账本单位（≈页面 0.2–0.35 px），位置也对得上。同一仿射把账本里的港口、市集、教堂多边形放到页面坐标。
- **匹配率**（页面在当年存在的房 ∩ 当年账本有户）：

| 年 | 页面在立 | 对上 | 匹配率 | 对不上的原因 |
|---|---|---|---|---|
| AF40 | 2,638 | 2,638 | 100% | — |
| AF50 | 4,078 | 4,078 | 100% | — |
| AF60 | 4,465 | 4,465 | 100% | — |
| AF65（骤降） | 4,465 | 4,397 | 98.48% | 68 栋账本在 AF62 拆 55、AF65 拆 13；页面 houses.json 只到 AF60，拆毁年写的 9999 |
| AF70 | 4,465 | 4,397 | 98.48% | 同上 68 栋 |

  这 68 栋在页面上画虚线框，卡片写「账本里这栋房在建城 N 年拆了」。反方向：账本里落在页面范围内、页面没有的 AF61 后新房 AF65 113 栋、AF70 208 栋——页面没有它们的多边形，画不出（需要上游补 houses.json）。所以不需要另建映射表。

## 2 映射规则表

经济量的单位：折粮的钱（1.0 = 一人一年口粮）；贫困线 3.0（v21 `A.poverty`）；房值 V_h = 30，维护需求 = 2%×V_h = 0.6/栋·年（v17 修房上限）。「房主」= 自有房的户自己；租住户取房东（`landlord`）。

| 表征 | 经济量直接推出 | 映射假设 | 推不出 |
|---|---|---|---|
| **房屋维护：新修** | 房主当年 `修房(付营造)` ≥ 95% 维护需求（0.6×房主房数）；或账本建成年距今 < 3 年 | 一年修满就算「新修」，不看前几年 | 墙面颜色、哪一面墙修了 |
| **寻常** | 0 < 修房 < 95% 维护需求 | — | — |
| **失修** | 修房 = 0，房主净收入 ≥ 3.0（没有超过 6 个月基本开支的盈余，按 v17 户规则就不修） | 只用当年一年的流判断（快照年之间没有逐年房况存量）；穷到不修 = 外观上「失修」 | 失修了几年、破到什么程度（模型没有房屋折旧存量） |
| **破败** | 修房 = 0 且房主净收入 < 3.0 | 同上；破败 ↔ 失修 只差房主当年过没过贫困线，所以逐年会来回跳（AF64→65 页面 273 栋破败→失修、267 栋失修→破败） | 塌没塌、能不能住 |
| **门面：开张的铺子** | 生计 ∈ 面包/手工铺/港货商/兑钱商/牙人 且当年卖货进账（买卖:*、出口:*、港口采购）> 0 | — | 具体卖什么（v21 只有「手工铺」，不分陶匠/织工/鞋匠） |
| **作坊开工** | 生计 = 作坊 且当年手工品进账 > 0 | — | — |
| **关门的铺面** | ① `craft_conv` = 1：原手工铺营收连续两年 < 5.5 关门转业（v21 进出规则）；② v19 原定手工铺、当年生计已不是铺；③ 铺户当年零营收 | 关了的铺面门板还在（房子不改用途），所以画成「关门的铺面」而不是住家 | 关了几年（flows 只有快照年） |
| **行号** | 生计 ∈ 营造/装卸行/港仓/船修/运水人/渔户/菜农 | 有营生但不是临街卖货的铺面 | 招牌样式 |
| **住家** | 其余（雇工、码头脚夫、兵户、体面户……） | — | — |
| **行当招牌** | 生计名（v21 `livelihood_names` 17 类） | — | 细行当；**页面原有人家卡片里的行当（陶匠、织工……）是房屋 id 散列出来的，和经济层生计不一致**（例：埃及人巷 70 号卡片写陶匠，经济层是雇工），本版并列显示，没有改原卡片 |
| **出租 / 租住** | `houses_owned` > 1 → 另有 n−1 栋出租；`landlord` ≥ 0 → 租住（卡片给房东门牌） | 房东实体序号与流里 a/b 同口径 | 哪一间出租 |
| **贫困户** | 净收入（收入 − 营业支出，口径同 v18 `BUSINESS_OUT`）< 3.0；核对：AF70 全城 960 户 = v21 报告 `poor_net` 960 | — | — |
| **门口无炊烟（灶冷）** | 当年领 `施舍(亏空)`：亏空借不到钱、由主教库补（v21 rules「亏空施舍」） | 补亏空的户 = 灶冷 | 哪几天断炊 |
| **典当** | — | 「向放债人借」（v2 债：同区有房面包师/体面户放的）最接近典当，卡片写「向放债人借了 x」；其余借贷按来源写亲属/同行会/坊长/盈余户/官贷（按当年文件 rules 文字认来源） | **当铺、抵押物**：模型里借贷都是无抵押无息的，没有典当 |
| **领施舍** | 当年 `施舍`（主教库施舍上年收入 < 线的本派户，≤2.0/户） | — | — |
| **街道人流** | 本街各户当年卖货进账合计 ÷ 本街户数 | 卖得多 = 人多；四档门槛固定取 AF70 基准各街分位（40/75/92%：0.70 / 5.60 / 12.29 每户），各年同一把尺 | 真实行人数、什么时辰挤 |
| **摊位密度** | （开张铺 + 开工作坊）÷ 本街户数 | 铺面即摊位 | 路边流动摊（页面原有的摊位动画仍按房子密度画，没接经济层） |
| **乞讨点** | 本街领施舍 + 亏空施舍户数 | 本街 ≥ 2 户领施舍且本街房屋离页面内教堂 ≤ 300 px → 标「乞讨点」 | 乞丐站在哪个门口 |
| **作坊烟与声** | 本街手工铺 + 作坊当年手工品进账合计 | 产量 ∝ 烟与声；四档门槛取 AF70 基准有手工产出的街分位（47.2 / 143.5 / 519.7） | 声音的种类 |
| **码头船数** | 全城到港量（v21 `sector.ships`；骤降路径 `shock_path`）× 本港装卸费份额（装卸费按到港量分给本港装卸行） | 船数按装卸费比例分到四个港 | 船型、停泊位置 |
| **脚夫人数** | 本港（`home_port`）码头脚夫户 + 当年领 `工钱:港口` 的本港雇工；零工 = 领 `工钱:零工(码头)` 的本港户 | — | — |
| **仓库满空** | 本港 `港费:仓储` 进账 ÷ 同港 AF70 基准值 | ≥ 0.85 满、≥ 0.45 半空、否则空 | 仓里装的是什么 |
| **市场** | 各市场节点（户 `market` 列）开张卖家、关门铺面、卖货进账合计 | — | 摊位布局 |
| **教堂施舍队伍** | 领施舍/亏空施舍户按 v13 户籍教区归到教堂（AF64/65 用 AF60 户籍、AF66 用 AF70 户籍） | 领施舍的户都去本堂排队 | 排队时刻 |
| **「为什么看起来这样」** | 页面把上面的经济量填进 surface JSON 里的 `why` 模板（Python 写模板、页面只做替换） | — | — |

页面范围内的设施：使徒教堂（页面上缘外 74 px，标在边上）、阿里乌聚会所、阿里乌砖堂（AF64 起）；狄奥多西港在页面下缘外 341 px，标在下边沿（带 →）。其余三港、四个市集都在别的街区，只在 JSON 里，面板不画。

## 5 局限

- 房况只用快照年当年一年的流判断，没有逐年房屋存量；破败/失修会因房主当年净收入在贫困线上下而来回跳。要稳定，得在经济模型里加房屋折旧存量（不在本版范围）。
- 快照只有 AF40/50/60/70（基准）与 AF64/65/66（骤降路径，本目录现跑）；页面滑杆 1–60 年，「跟随年代」用最近快照（<45→40，<55→50，其余→60），40 年前显示 40 年。选 65/70 时滑杆停在 60（底图只画到 60）。
- 页面原有卡片里的人家行当、人名是散列推演，和经济层生计不一致，本版没有动原卡片，只在上方加「表面」块。
- 页面没有 AF61 后新建的 208 栋房（上游 houses.json 只到 AF60），AF65/70 表面层少了它们。
