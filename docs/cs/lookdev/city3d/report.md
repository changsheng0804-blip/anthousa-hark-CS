# 全城 3D：南港渲染器推到全城，分块流式加载（2026-10-20，主人「可以」）

页面：`docs/living/nodes/city/3d.html`（`?shot=1..4`，机位在 `docs/living/nodes/city/3d/shots.json`）。
总览：`docs/cs/lookdev/city3d/overview.jpg`（航拍、中景、另一街区人眼高、全城页里的南港、南港页机位 3/7 逐像素不变）。数字：`numbers.json`。
沙箱是软件渲染（swiftshader），秒数只作相对参考；**帧率和卡顿要在 Mac 上测**。

## 怎么做的（一条主线：独立页 + 同一套模块）

- **模块没复制**。全城页的导演是新文件 `docs/living/nodes/nangang/3d/citycore.js`，import 的就是南港 3d.html 用的那 9 个模块。
  模块只多认 ctx 上的可选参数，南港 core 不给，所以南港一个像素不变：
  - `ctx.noOuter`（terrain：不画南港的区外烘焙，区外由全城远景接）；
  - `ctx.landmarkIds`（buildings：landmarks 没接手的同类地标画旧通用占位——创城者广场、四柱廊集市用旧柱廊，大宁芙泉、纪念物用旧半圈柱；buildings 没部件的 kind（教堂、竞技场、皇宫、城堡、城门、浴场、市场）不再落成粮仓，交给远景剪影）；
  - `ctx.ox/oz`（flora：树的样子按全城坐标定，窗口挪了不变）；
  - `globalThis.CS3D.crowd = null`（crowd：全城页先不取人群）。
  另外 `arch/house.js` 把墙色/瓦色表 `export` 出来给远景用，`landmarks/index.js` 导出 `IDS`。都是零行为改动。
- **数据**：`tools/cs/nodes/city3d_chunks.py` 读 `docs/living/nodes/city/nodes_net.json`（net.py + water.py 后的全城节点：17646 户入街、街网全城一次长、和瓦片街巷层同一份），
  按**瓦片格**切块（`tiles/meta.json`：455 px 一块，13×14 格，坐标 = 瓦片级 0 像素 = 全城节点像素）。一个要素只进一块（房子按中心、街按中点、栈桥按中点、树按点），所以块边没有重复房子/重复街。
  - `3d/base.json`：W/H、elev（同 nodes.json schema）、等高带、陆地/海/港池/石堤、29 座地标、水道桥、分块索引；
  - `3d/chunks/f_i_j.json`：近景整块（nodes.json 同 schema 的 features + trees，全城坐标）；
  - `3d/chunks/l_i_j.json`：远景简块（房子 `[id,y0,y1,p8,ht,fn]` + 街 `[k,w,x0,z0,x1,z1,y0,y1]`）。
  - 有内容的块 116 个（其余是海）。近景块 gzip 合计 871 KB、最大一块 19 KB；远景块 gzip 合计 622 KB；base 162 KB。全部数据 7.46 MB 原始 / ≈1.66 MB gzip。
- **近景 = 跟着看点走的 4×4 块窗口**（1820 px ≈ 1.5 km，和南港一个页面框一样大）。窗口里的要素平移成窗口局部坐标，交给模块按南港那套 init/paint/build 建——模块眼里窗口就是一个「街区框」。
  看点离窗口中心超过一块才挪（滞后一块，免得来回重建）；挪的时候先把要用的块取齐再一帧之内换掉，外面一圈预取，两圈以外的近景块丢掉。
- **浮动原点**：场景原点 = 窗口左上角，窗口挪了相机、看点、远景组一起反向平移，画面不跳（浮点精度也一直在窗口内）。
- **远景**（`3d/citylod.js`）：每块一张 28×28 格粗地形（带 12 px 裙边）+ 一块房子体块网格（一户约 14 个三角形，墙色/瓦色/平顶按 house.js 同一套房号哈希）+ 29 座地标剪影（按 kind 的体块，大块按 ≤40 px 格子落成台地）。
  远景地面贴图直接调 terrain / water / streets 三个模块自己的 `paint`（全城 ctx），再画一层屋顶色房基（航拍时一户只有一两个屏幕像素）。窗口里的块藏远景，窗口外的块没有近景。
- **接缝**：全城一个 `ground(x,z)`（同 core 的公式），近景 4 px 网格、远景 16 px 网格都从它取，只差插值；远景块四边、近景窗口四边各一圈下垂裙边，盖住插值差，不露天。陆地/海/港池由全城水陆蒙版一次算，跨块连续；海是 water 模块的大海面（40000 px，跟窗口走），城外一圈都是海。
- **地标**：3 座做好的（纪功柱、大宁芙殿、狄奥多西广场）在窗口里时由 landmarks 模块整座建；其余 26 座在窗口里画 buildings 的通用占位（有部件的）或剪影体块；窗口外一律剪影，任何距离都看得见。
- **年份**：滑块对全城生效：重算水陆蒙版、远景贴图、远景房子/地标剪影，再重建窗口（`numbers.json` 里有第 20 年的验证）。
- **镜头很高（> 2600 px ≈ 2.2 km）时收掉近景窗口**，整城只画远景——航拍首屏不用下任何近景块；`farFor()` 按高度把 far 拉到 ≤ 40000（雾跟着 far 走），整城不至于全埋在霾里。

钩子：`window.__ready`、`__trisTotal`（当前画面里可见的三角形：可见链 + 视锥，THREE.LOD 只数当前档）、`__trisPer`（按模块/远景分）、`__chunkStats`（窗口、已载块、远景块可见/隐藏、重建次数、字节）、`__bytes()`、`__applyShot(s)`、`__view(...)`（全城坐标）、`__setYear(Y)`。

## 已知缺口（按我觉得的轻重）

1. **窗口挪动是一次整窗重建**：Mac 上估计几百毫秒的一下卡顿（沙箱 3–16 s 不算数）。新进窗口的那几块从体块变成细模是「换」不是「渐变」；滞后一块 + 远处起霾能盖住一部分。要更顺就得把模块改成按块增量建（动 9 个模块的 build/dispose），这次没动。
2. **近景/远景的明暗差**：阴影只在近景窗口里（太阳阴影相机本来就是 ±1800 px），窗口边上能看出窗口里暗一点、细一点；远景地面贴图 ≈0.64 texel/px，比窗口里粗。
3. **地标**：除 3 座做好的，其余是通用占位/体块剪影——教堂、竞技场、皇宫、城堡、城门、浴场是方块（大块落成台地），近看很粗。长卷 city/scroll.html 里已有教堂、皇宫、竞技场、卫城、城门部件，可以按 landmarks 的规矩一座座搬进 3D。
4. **城框**：全城陆地在瓦片框的西边、北边被直线切断（数据到框为止），外面直接是海，西边的陆墙外看着像一道直崖。要补得烘框外地形（类似南港的 terrain/outer）。金角湾北岸的高程格本身很粗，远看有方块状明暗。
5. **人群没上全城**（`CS3D.crowd = null`）：全城 crowd.json 8.7 MB，要按块切再接，这次没做。
6. 全城页用的是 net 版节点（`nodes_net.json`，和瓦片街巷层一致），南港页用的是旧的 `nangang/nodes.json`：所以全城页里南港的房子排法和南港页不一样（不是 bug，是两份数据）。
7. props/flora 里按「第几座栈桥」取的哈希会随窗口里有哪几座栈桥变，窗口挪了个别船型可能换（树已改成按全城坐标，不会换）。
8. 帧率：全没在真机上测。
