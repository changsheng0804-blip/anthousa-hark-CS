## 合并时 core 做了什么
- **buildings 落地**：粮仓山墙浮雕（壁柱、腰线、檐口）+ 仓间空当 2.6→5，A/B 看过留了带浮雕的版本；buildings 的 README/numbers.json 补了 sky 进来后的数字。
- **相机 far 9000 → 16000**（sky、terrain 要的）。跟着改的两处小修（模块文件，合并特许）：terrain 的远岸环半径跟着 far 走（`far × 0.922`，雾在环上的比例不变），并削掉亚洲岸近段单列尖峰；water 的海面平面 20000 → 40000，不然机位 3 能看到海面的边。
- **机位 3 改了**（terrain 要的）：pos 不动，target `[1150,0,1560]` → `[1808,0,1901]`，俯角 ≈23° → 16°，方位往左转 17°。地平线落在 ≈0.14（参考图约 0.12–0.15），东岸、远岸和王子群岛进画面。天空带 0–0.12 → 0–0.14，其余带不变。**旧基线的机位 3 数字不再可比**：在 3ad741d 上用新机位重拍了基线，见 `baseline_shot3_newcam/`，下表的机位 3 基线都用它。
- **`__modStats` 修正**：三角形改在 `__still()` 画完以后再数一次（crowd 的实例数在 tick 里才定，之前在 build 时数到 0 或上限）；新加 `window.__trisTotal`、`window.__modStatsNow()`；`render.py` 把每个机位的三角形和 `__crowdStats` 写进 `render.json`。
- **sky：山墙不再是黑的**。buildings 进来后机位 4 粮仓山墙在背光里压成 #010000。按美术圣经「阴影冷蓝灰，不是黑」：天光 1.1→1.9、天色偏冷灰、地面反光提亮（主要照竖墙）；为了不把反差冲没，太阳 8.3→10.2、暗部反差 0.30→0.42、亮部反差 0.95→1.6。太阳方位**没动**（300°）：268–288° 都试过（`merged/sky_tuning.json`），粮仓更亮，但机位 2 整条街被照亮，离参考更远。受光墙在 #e1ceb7–#efd3af 之间，不比 #e9d6b0 亮多少，墙色没动。

## 第 3 轮提案（3 件）
1. **机位 2 和粮仓「有人在干活」**：主人先定机位 2 要不要按参考改成逆光（太阳在街尽头；只能改机位或太阳，二选一）；同时 people 管线给粮仓—栈桥加搬运工路线，crowd 在机位 4 做近景关节人。验收：机位 2 sky 全过、机位 4 看得见 ≥40 人。
2. **硬码头**：core 锐化港池蒙版，buildings 建竖直码头石墙（带勒脚和系船石），water 画水线湿痕。验收：机位 4 码头带、机位 1 水带边缘不降，港池岸在并排图上读成「墙」而不是「坡」。
3. **城不止南港**：terrain 用全城节点把区外铺成远景屋顶（实例 + 远档），机位 3 远海加远船/浪纹，sky 把地平线霾调薄调冷。验收：机位 3 0.14–0.40 带边缘 ≥0.08，三角形总数仍 ≤2 M。同一轮在主人 Mac 上测 4 机位帧率，先过预算再加东西。
