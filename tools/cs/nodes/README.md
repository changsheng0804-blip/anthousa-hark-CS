主人定的方向：底账 → 节点 → 渲染器。学 WorldGacha（oyasumi-gamedev）的方法，没用它的代码。
- `build.py <q>` 按顺序跑七个节点：地、水、栈桥、街、房、地标、空地，写出 `docs/living/nodes/<q>/nodes.json`（「OSM 形状 + 年份」的中间层）和 `recipe.json`（节点种子和参数）。同一份配方永远得到同一个街区；随机数按位置取，改一处不牵动别处。
- 页面 `docs/living/nodes/<q>/index.html` 只吃 nodes.json 和底账房屋几何，一张栅格图都不用。地标是代码部件（柱廊、粮仓长屋、水殿、蓄水池穹顶、救济院），和房子用同一套 3/4 俯视画法。
- 远近分层：拉远时每个年份只烤一张整图；中间层按 256 像素分块、按 2 的幂级别烤，最多留 90 块；拉得很近时只画视口里的矢量。
- 南港基线（沙箱软件渲染，1100×1000）：首屏 1.0 秒，3 个请求，1.1 MB（gzip 后），堆 28 MB；z 0.48/1.2/2/4 平移约 60 fps；换年份 150 ms。旧版同条件下是 1.5 秒、31 个请求、8.8 MB、堆 88 MB。

## 3D 渲染器（2026-10-17，主人「先看看 3D 效果如何」）
`docs/living/nodes/nangang/3d.html` 吃同一份 nodes.json，只换渲染器。为此给中间层加了一样东西：高程格 `elev`（每 16 像素一点，单位分米），2D 只用等高带，3D 要真起伏；这就是「换渲染器验 schema」测出来的缺口。
- 地面：高程格起伏，乘 1.3 倍夸张；陆地、等高带、港池、街、地标地皮画进一张运行时贴图披在上面。岸边按蒙版覆盖率在海底和陆地之间平滑过渡。
- 房子按底账占地立墙，屋顶是四坡顶或平顶，所有房子合成一个网格；地标用代码部件（柱廊立柱、纪功柱、粮仓双坡长屋、水殿半圆柱列、蓄水池穹顶、救济院院落）；防波堤是挤出的多边形，树是实例。换年份时整批重建，约 1 秒（沙箱软件渲染下测得）。
- three.js r160 放在本地 docs/living/nodes/lib/three（MIT，许可证随附），不走 CDN，国内打开更稳。
- 沙箱没有 GPU，软件渲染只有 1–2 fps，这个数字不能当真；真机帧率还没测。

## 民居规则（scroll.html houseGeom，2026-10-17，主人「试一下」）
nodes.json 的房子多带三样底账字段：ty（上游 house_types 的类型：casa/row/insula/hall/std/flat）、fr（临街边序号）、po（有无柱廊）。页面按类型盖房，细节按房号哈希：
- row 连排铺面：石砌底层开拱门，楼上木构或抹灰挑出街面，木骨竖线，遮阳篷，柱廊；屋脊平行街。
- insula 公寓楼：砖墙，每层一道白灰带，窗格，底层拱门，缓坡四坡顶。
- hall 货栈长屋：长轴双坡，扶壁，大门。
- std 火后标准屋：故意一模一样。
- flat 平顶：女儿墙，有的有葡萄架。
- casa 民居：一到两层，门窗位置、四坡/双坡（两个方向）/平顶露台加小阁、外梯、后披屋、后院矮墙都随房而变；背面侧面也开窗（镜头从海上看）。
门窗、带、柱是贴墙的小面，靠线稿着色器的颜色分界自动描边，不用贴图。南港 60 年约 71 万顶点，换年重建约 1 秒（沙箱）。全城铺开前要做远景简化（远处只要盒子加屋顶）。
街区框外的户不画（框外没有陆地）。

## 路网节点 net.py（2026-10-17，主人：房子跟着路重排，更看重方法）
学 WorldGacha 的町节点：① 地形 = 底账 SRTM 高程 + 水滴侵蚀 + 地标底下削平台 ② 可达代价（坡²，水和地标不可走）
③ 干道 = 锚点（框边城市路口、地标门、栈桥根）之间的最省力路径，按最小生成树先后修，修过的格子变便宜所以会并路；抹圆下水就退回
④ 小街 = 张量场流线（干道/海岸/等高线/基础格网按 2θ 叠加 + 低频扰动），从干道两侧长出、交替两族，没人家（需求场）就到头，断头 16 像素内接到最近的街，孤街不要
⑤ 地块 = 沿街两侧按门面宽/进深切，干道先切 ⑥ 入户 = 底账每户按年份先后挑离原位最近的空地块，挨着已有人家的加分（连成排），临干道加分；同块地年份不重叠可接着盖
⑦ 验收写 net_report.json：街不下水、坡 p95、户全入、每户门脸离街 <8、路网连通、地标和框边路口都接上。
梅塞大道（canon）、海岸、港池、地标、每户年份/用途原样来自底账；只有路怎么走、户落在哪块地是长出来的。种子在 recipe.json seeds.net_*，参数 recipe.json net。
输出 nodes_net.json，页面 scroll.html?n=net；俯视对比 net_cmp.py <q> <Y> [窗口]。
