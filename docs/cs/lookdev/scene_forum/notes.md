## 参考页怎么做交互（curl 下来读的）
- 悬停：底部左边一行状态栏换成「名字 / 拉丁名 / 一句话」，能进的建筑多一行「click to go inside →」；手机不悬停。
- 点：点人或建筑把那行**钉住**，再点同一个放开；点能进的建筑直接进。
- 进门：换成室内小场景 + 左边一张卡（标题、年代、「read the story」折叠、Happening now 几个人、出处），「← back to the Forum」回去。
- 镜头：拖动平移、滚轮 / 双指缩放、Q/E 或按钮转 90°；有暂停、声音开关。
我们照这个做了：底部一张签（悬停换、点了钉住）、头顶挂名字签、能进的多一个「进去看看 →」、进门换镜头 + 卡片、四个按钮（左转 / 拉远 / 拉近 / 右转，Q/E 也转，Esc 出门）。没做：声音、暂停、一天里的时间（见「没做的」）。

## 门（深的藏在门后，一次只露一件）
- **4 间柱廊铺面**：北（丝绸商）、南（银钱商）、东（金匠）、西（香料商）各一间 = 那一翼中间那个摊子所在的开间。点「进去看看 →」：镜头飞进柱廊、人眼高、隔两开间回头看铺子；左边一张卡：铺子是谁家的、一句话，「里面是谁」**一次只露一个人**（摊主 → 下一位：同户搭手的 / 来问价的），卡上是谁，画面里就给谁头上挂名字签。
- **纪功柱基座的小门**：只出卡（柱身里的螺旋梯，Columbia）；底账里没有守柱子的人，卡上写「此刻门里没有人」，不编人。
- 柱廊外墙上的拱形门洞（forum.js 本来就有）就是铺面门；进门不建新几何，用的是柱廊本身的里面。

## 镜头
- 桌面：左键拖转、滚轮缩放、右键平移，Q/E 或按钮每次转 45°；手机：单指转、双指缩放平移，四个按钮在底部中间。镜头目标关在广场周围 ±170 px，最远 520 px。
- 开场机位：西北高处往东南看（低太阳在西北偏西，受光的南、东柱廊和纪功柱在画面里，背景是港）。
- 太阳的影子框从全南港（3600 px）收到广场 ±260 px：人和柱子的影子清楚了，广场外很远处没有影子（这一页的镜头到不了）。
- 手机（触屏）自动 `quality=preview`（关掉水面倒影那一遍）；`?quality=high` 强制高档。

## 没做的 / 差的
- **一天里的时间**：参考页有一个下午的钟（人随时间换事）。sky 模块的太阳是固定的低太阳，这页没做时间滑块；人的去处也只有一个下午。
- **官员**：任务里说「凯旋门下的官员」，户籍里没有官员（folk.py 的人全是住户），所以凯旋门下站的是身份 = rich 的住户，没编官员。
- **脚夫**不是广场周围的人家（周围没有扛活的），是全南港离广场最近的 20 个 laborer；他们户籍里的路线是去码头，这页让他们在梅塞大道上过广场。
- 「摆摊」「排队写状子」「去宁芙殿打水」是按行当 / 去干什么派的，不是 folk.py 算出来的路线；所以签上分开写「此刻」。
- 人和人互相会穿过去（没有避让）；逛摊子的人在两个摊子之间直线走，偶尔擦过柱子。
- 摊桌、抄写员的桌凳是素盒子；柱廊里背光，摊子颜色要贴近才看得出。
- 建筑的指认是看不见的盒子：柱廊盒子包着整个廊子，指廊里的人优先给人；实心的（柱子、凯旋门、东门楼、宁芙殿）会挡住后面的人。
- 进门只有 5 扇（参考 11 座）；没有真正的室内小场景（是镜头进柱廊 + 卡片）。
- 帧率：沙箱 0.2–0.4 fps（SwiftShader），**真机帧率没测**；300 个关节人 + 全南港 1.9 M 三角形在 iPhone 上可能吃紧，吃紧就先降关节人上限（`fullM` / `maxFull`）或只建广场周围的模块。
