## 3 种类型（参考图 `refs/ref_A_insula.jpg`、`ref_B_domus.jpg`、`ref_C_warehouse.jpg`，generate_image，看过无教堂/十字）
| 类型 | 样子 | 怎么挑（`3d/arch/kit/typology.js`，先中先得，只看底账属性 + 户 id 种子） |
|---|---|---|
| — | 不换，照旧 box | `ty` 以 `lm:` 开头（喷泉、面包台阶、肉市这类小地标户） |
| C 仓 / 作坊 | 砖石夹层墙（92%）、砖拱大仓门隔间排、高处通风缝和小拱窗、顺长边两坡顶 + 山墙、主门木雨棚、吊货梁 | `fn ∈ {dock, horrea, water}` 或 `ty = hall`，或 `fn ≠ homes` 且离港池/栈桥 < 36 像素（≈30 m）且种子 < 0.7 |
| A 临街公寓 insula | 底层一排铺面（开着的有货架和罐、柜台；关着的是门板），上层窗 + 窗框 + 窗台 + 半开木百叶，层间线脚，临街木挑廊（maenianum，有栏板和斜撑），没柱廊时铺面上有条纹遮阳布，檐下椽头、瓦当 | 层数 ≥ 2，且（`fn ∈ {shops, market}` 或 `ty ∈ {row, insula, flat}` 或 `po = 1`）且临 m/s 街（`ty = insula` 不要求）；另外 `fn = homes`、层数 ≥ 3、临 m 街的，种子 < 0.5 |
| B 院宅 domus | 临街素墙：一扇石框门 + 门槛，几道高窗缝，上层少量窗；占地够大开内院：环形瓦顶向院里收、四面朝院的墙、回廊柱 + 额枋 + 单坡廊顶、石铺地、雨水池 | 其余全部。开内院：不是平顶、短边 ≥ 12 像素、面积 ≥ 200 平方像素、层数 ≤ 3 |

层数 = round(檐高米 / 3.1)，1–4 层；C 是 round(檐高米 / 4.2)，1–2 层。临街边：柱廊户用柱廊那条边；其余取中点离街（任何等级，顺着这条边）最近的边，优先 m/s；找不到就按种子取一条边当门面。
种子全用 `ctx.hsh(户 id, 2xx/3xx)`，同代码同年份同图。颜色：墙色、瓦色直接用 box 版的那户颜色（远近切换不跳色），百叶 5 色、遮阳布 5 色都在 ART_BIBLE 衣物/木色的灰调里。

## 不变量（底账）
- 墙线 = box 版墙线（底账 `p` 的 0.92 内缩，柱廊户再退一个廊深），檐高 = box 版（`ht × 1.15` 像素），层高按檐高均分（底层高一点），所以**屋檐不高过底账**；屋脊坡度同 box 版（≈23°）。
- 凸出物（窗台、挑廊、遮阳布、雨棚、吊货梁）离墙 ≤ 这条边到底账占地边的余量 + 0.5 像素（同 box 版的出檐），挑廊最深 1.1 像素（≈0.9 m）。
- 年份：rec 只在 `live(f)` 的户上记，年份重建时整套重来。
- 柱廊（buildings 的柱子实例 + 额枋 + 廊顶）不动：近处只塌掉楼身那段顶点，柱廊留着。

## 做法（文件全在 `docs/living/nodes/nangang/3d/arch/kit/`）
- `flag.js`：照 `docs/flags.js` 的规矩读开关（3d.html 是 core 的文件，没载 flags.js）；没点名时不发任何请求。
- `buildings.js` 只改了 3 处：`house()` 多一个 rec 参数（关时是 null，不进任何分支）、建完把各桶网格交给 kit、多一个 `tick`（关时直接 return）。`arch/house.js` 只多记区间、`frontage` 加了 export。
- `index.js`：tick 里按相机距离挑近圈（≤ 180 像素 ≈ 150 m 进，> 200 才退；相机动 ≥ 10 像素才重算），按 48 像素的格合并（一格 2 个网格：图集材质 + buildings 的瓦材质，draw call ≈ 2 × 近圈格数 ≈ 30–90）。进圈：把 box 楼身顶点塌成一点（面积 0，不画、不投影），生成细模；出圈：还原顶点、删细模。交互时每帧最多 5 ms，静帧在 `__still()` 时一次做完。
- `atlas.js`：一张 2048×1024 画布图集（灰泥 / 砖石夹层各 10 种墙格 + 木板、栏板、条纹布、白、铺地、水），代码画；`gen.js`：参数化生成器；`typology.js`：挑类型。

## 说实话：还差什么
- **机位上的数字几乎没动**：机位 2 的近处临街户都有柱廊，底层被廊遮住，box 版的立面贴图本来就画了窗和铺面，换细模后边缘密度反而 −3%（墙面大块、更平）；机位 4 近圈只有 32 户、在画面里很小。细模的好处在「深度」（挑廊、出挑的窗框和百叶、檐下椽头、雨棚的影子），要人眼高、走近、侧光时才显，固定机位的整带统计量不出来。
- 近景 B 素墙按类型就是「素」，比 box 版带拱窗砖带的立面看着更空（机位 6 左前那户）。要不要给 B 加砖带 / 门头装饰，等主人看。
- 内院只有 1–2% 的户够大（南港民居中位占地 ≈ 106 m²），机位里基本看不见；高空机位 3 离地 520 像素，在近圈外。
- 远近切换是硬切（户为单位，进出圈 20 像素的回差）：走动时 150 m 处会有一户户换模的跳变，Mac 上要看明不明显；不明显再考虑淡入。
- 没做：铺面招牌、晾衣、屋顶陶罐 / 花盆、门口台阶的高差（坡地）、窗里的灯。人、货、树归别的模块。
- 帧率全没测：Mac 上机位 2、5 开 / 关各一次（`quality=high`），看 fps 和最差一帧；细模 draw call 约 2 × 近圈格数（机位 2：45 格）。
