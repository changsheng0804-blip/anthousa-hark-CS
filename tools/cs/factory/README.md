# CS 线 · 街区生产线

目标：用底账「长」出一个新街区，人只做一件事——挑。

```
底账 world.json ──grow.py──▶ 街区数据 + 引擎草图（每栋房子、路、港、公共建筑、火烧地，逐栋对齐）
        │
        └─ 草图 + 已有画作的风格 ──AI 画师（并行 N 张）──▶ 候选画
                                                    │
                       critic.py 自动评分（房子命中率 / 空地干净度 / 水 / 火烧地）
                                                    │
                       reroof.py：从 AI 画里剪下屋顶当零件，按底账一栋一栋铺回去
                                                    │
                       页面（同一份 index.html，scene.json 换一个街区）──▶ 所有者：留 / 再来
```

## 一个街区怎么长出来（南港是第一个）
1. `python engine/build_all.py` —— 从提案重建 world.json。
2. `python tools/cs/factory/grow.py nangang 445 418 40 50 60` —— 截世界框（128×144，与已有街区同比例），出 houses.json、frame.json、每个关键年代的草图 base_Y.png。约 3 秒。
3. 每个关键年代把草图 + 风格参考图交给 AI 画师，各画 2 张（提示词要点：每个红块就是一栋房子、位置不许动；火烧地、港、公共建筑按草图）。
4. `python tools/cs/factory/critic.py nangang 50 候选1.png 候选2.png …` —— 选分高的，再用眼睛看一眼。
5. `python tools/cs/factory/reroof.py nangang 50 候选.png ng_af50.jpg` —— 屋顶归位到底账。约 5 秒。
6. 写 scene.json（关键年代、标题、此刻滚动条）和 city.json 的地标（名字和故事只用 chronicle 里有的事实）。
7. `node tools/cs/check_talk.js`（把目录换成新街区）—— 每扇门的回答零空值。

## 第五段：验收（accept.py）—— 拉取 → 比对 → 验收 → 修改

`python tools/cs/factory/accept.py nangang [--pull] [--live]`

- 拉取：上游底账有没有新提交（--pull 合并）；world.json 过期就重算；用最新底账把街区重长一遍，逐栋和线上数据比。
- 比对：页面上的数字（栋数、烧毁数）、地标年份、地标是否在框内、静态文字有没有串别的街区、「怎么做的」写的年代、街区之间能否来回走。
- 画面：房子对位、水、火场黑、灰烬是否漫出真实火场、公共建筑旁的房子有没有被吞掉；另出一张公共建筑目检表 `out/<q>_landmarks.jpg`（青框已建、紫框未建），机器测不准的「建筑画得对不对」看这张。
- 线上：每个文件线上和本地 sha256 一致。
- 结果写进 `docs/living/<q>/ACCEPT.md`，每个不合格项带「怎么修」。退出码 0 才算验收通过。

第一轮（建城 60 年版南港）查出 5 项，已修：
1. 亚历山大粮仓故事里第一个年份是 48（火灾），没写「建城 55 年」→ 改文案。
2. 南港静态文字串了干山的介绍 → 文字改由 scene.json 的 info 提供。
3. 50 年灰烬漫出真实火场 23.4% → reroof 保护区从「圆圈 + 15 像素」收紧到底账地块，现 5.4%。
4. 50 / 60 年狄奥多西粮仓旁的房子被吞（覆盖 0.18 / 0.53）→ 先贴保护区再铺房子，火场里幸存的房子也照底账铺上。
5. 目检表发现候选 a 把粮仓画成了烧剩的空壳（底账里粮仓没毁）→ reroof 加 DONOR：火场用候选 a，粮仓借候选 b。

## 第六段：打通（cs7）—— 底账一变，画和心跳自己跟着长

```
底账变了 ─accept.py --fix─▶ 只有房子变：repaint.py 照 scene.json 的 paint 配方重铺屋顶，只动变了的那几栋（量局部性）
                         ├▶ 公共建筑变了：报出是哪一座，只把那一块交给 AI 画，记进 paint 的 donor
                         └▶ heart.py 重算心跳位置：泊位、系缆桩、锚地、每艘船的水路、码头站人处、孩子爬的港墙、扛包到粮仓的路
```
- `heart.py <q>`：规则（借自 castle-town-sim 的「中心按规则放」）——泊位在离水 ≤8 像素的岸上，前面水深 ≥24、能从海上开进来、码头不压房子、离粮仓走得最近、港里的岸加分；港口多边形四周是墙，口子开在离粮仓最近、外面是开阔水面的那段；船走离岸远的水路；人沿街走（路 1、空地 2、穿房子 9）。目检图 `out/<q>_heart.jpg`。
- `repaint.py <q> [年] [--check]`：AI 原画存在 `raw/<q>/`，配方在 scene.json 的 `paint`。实测：50 年拆两栋房子，画只变 0.01%，一块。
- 新检查：港里画的是水（每年每个港）；心跳位置和底账算出来的一致。
- 第一次跑就查出：60 年两张候选都把狄奥多西港画成了一座大房子（之前的验收没查港）。已用 50 年那张的港局部补上。
