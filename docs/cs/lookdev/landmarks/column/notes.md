## 史料（底账没写的形制）

- Last Statues of Antiquity LSA-2458：螺旋浮雕柱，顶上是狄奥多西「巨像」，386–394；「几乎可以肯定约 50 m 高」（同阿卡狄乌斯柱）。http://laststatues.classics.ox.ac.uk/database/discussion.php?id=2832
- Columbia Istanbul Documentation Project：柱子 386 年立在广场中央，浮雕质量极高，有内部螺旋梯，**镀银青铜像**。https://mcid.mcah.columbia.edu/istanbul-documentation-project/forum-theodosius
- The Byzantine Legacy：仿图拉真柱 / 马可·奥勒留柱，**白色大理石，螺旋浮雕带自左向右上升**，约 40 m。https://www.thebyzantinelegacy.com/theodosius-column

## 假设（底账和史料都没定的，都是我定的，可推翻）

1. **柱头 = 科林斯式（茛苕叶）**：主人要；图拉真柱其实是多立克式，狄奥多西柱柱头形制无记载。
2. **总高 51.95 m**（修订后：台阶 1.1 + 基座到 7.3 + 柱础到 8.9 + 柱身 25.6 m + 柱颈环 0.35 + 柱头 4.0 + 像座 3.8 + 像 9.3；ff84e83 是 51.05 m：基座 8.75、柱身 27、柱头 2.6、像座 3.0、像 7.5）。柱头 4.0 m ≈ 柱下径 3.9 m，合科林斯柱头的常规比例。柱身直径 3.9→3.4 m（图拉真柱 3.7 m）；18 圈浮雕 + 一条真几何的螺旋边棱、17 节鼓石（鼓石接缝没做成几何棱，见下）。
3. **基座**：三级台阶 + 线脚 + 四面浮雕（南北：皇帝、士兵、角上胜利女神；东西：跪献的俘虏和押送士兵）+ 花环带 + 檐口。阿卡狄乌斯柱基座有浮雕，这里照那个意思画。
4. **像**：9.3 m（≈真人 5 倍；「巨像」；ff84e83 是 7.5 m）。姿势 = 训话手势（右臂前外伸）+ 左手托球 + 胸甲 + 皮条裙 + 左肩披风，**面朝西**（底账 60 年的西侧凯旋门）。颜色按风化的镀银青铜（暗银灰，修订后再压暗一点、高光收窄），没有鎏金。参考图 1 把像画成深色青铜、更胖更大——我只往它那边挪了一点（像 5.3→7.5 m、像座 1.65→3.0 m），没有照抄。
5. **施工中的样子**：58 年起有基座（「开工第二年」是假设），柱身按 (年−58)/6 线性长到 64 年，脚手架是 8 根立杆 + 每 2 m 一圈横杆 + 顶平台。
6. **参考图 1 的视点**比机位 5 高（生成模型把机位 5 的构图读成了略俯视）；只用它定柱子本身的样子，比形时按包围盒对齐，背景差别不算。

## 怎么做的（部件，全部在 `docs/living/nodes/nangang/3d/landmarks/`）

| 部件 | 文件 | 做法 |
|---|---|---|
| 旋转体 / 方形线脚 / 合并 | `kit/lathe.js` | 剖面点表 → 绕轴（柱身收分、柱础阿提卡线脚、像座）或沿正方形（台阶、基座线脚、檐口）；转角 > 35° 自动断法线 |
| 浮雕贴图 | `kit/relief.js` | 画布里画灰度高度（士兵、骑兵、旗手、俘虏、胜利女神、花环、画框）→ 自写盒式模糊 → 法线贴图 + 凹缝压暗的反照率；不用 `ctx.filter`（Safari 不支持） |
| 柱头 | `kit/acanthus.js` | 钟形芯 + 2×8 片参数曲面茛苕叶（锯齿叶缘、中脉、叶尖外卷）+ 12 个涡卷（TubeGeometry）+ 凹边顶板 + 花饰；`lod:'far'` 只出钟形 + 顶板 |
| 雕像 | `tools/cs/landmarks/bake_statue.py` → `column/statue_hi.bin`、`statue_lo.bin` | SDF（胶囊、椭球、圆台、圆角盒，平滑并）→ scikit-image marching cubes → 量化成 uint16 位置 + int8 法线；`kit/baked.js` 读。烘焙 0.5 s，浏览器里不再算 |
| 纪功柱本体 | `column.js` | 尺寸表 `DIM`、底账年份 `PHASE`、近档 / 远档 `THREE.LOD`（450 像素切换）、施工中的组、`?lmmask=1` 品红蒙版 |
| 模块壳 | `index.js` | `landmarks` 模块：按地标 id 分发，一座一个文件；core 的 MODULES 里只多了这一项 |

确定性：贴图和叶片只用底账的 seed（`forum_theodosius.seed`）推；没有 `Math.random`。

**做法**（都在 `column.js` / `kit/relief.js`，可复用）：
- `helixBand(perTurn, depth)`：沿浮雕贴图里亮边带的位置（v = u + 2/256）扫一条 4 点剖面的凸棱，下面是朝下的面——低太阳照不到，60 m 外是一条真暗线；法线贴图做不出这个。近档 72 段/圈，远档 16 段/圈，施工中按年份截到当前柱顶。
- 基座四面：画框外圈在面上，框里的场往里凹 0.12 m + 四圈侧壁（UV 和图集对齐，画框坐标取自 `frame()` 的内边）。
- `relief()` 新参数：`aoMin`（凹缝最暗到多少，原来写死 0.42）、`low`（「地」额外压暗，默认 0.1 = 原来）、`patina`（暖色风化，凹处多一点）。默认值和以前完全一样，别的调用不受影响。
- 反照率：柱身 [186,174,152]→[154,145,130]，基座 [188,174,150]→[148,139,125]，线脚 [190,178,156]→[150,142,128]，远档 0xbcae94→0x9b917f；像 0x968c7c→0x7c7366、镜面 0x8a7e6a→0x4a443a。材质仍是 Lambert（没有镜面亮点可压，压的是反照率 + 烘进贴图的凹缝）。
- 视差贴图没做：真几何（螺旋棱、凹场）在这个距离已经够，视差在 SwiftShader 下验不了。

**剩下的差**：阴面太黑（蒙版 p10 1.8 vs 9.1，柱头 p50 只有 6.5）——这是全局补光不够，按规矩不在地标里抬；受光面 p90 88.8 还比目标 85–88 高一点点（再压就开始发灰发脏，停在这）；蒙版饱和 0.61 vs 0.51、边缘 0.326 比参考 0.295 多 10%（螺旋棱规整，参考的更碎）；像仍是镀银青铜的暗银灰，参考画成深色青铜、更胖。
